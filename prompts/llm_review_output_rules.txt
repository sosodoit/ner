# LLM 검수 결과 출력 및 사전 활용 지침

## 결과 완전성(Output completeness)

- 입력된 모든 문장을 검수하고, 모든 문장에 대해 `reviews` 결과를 최소 1건 반환한다.
- 기존 개체명이 있는 문장은 모든 개체명을 `entity_id`별로 정확히 1건씩 검수한다.
- 기존 개체명이 없는 문장도 반드시 검수하며, 이 경우 `entity_id`는 `null`로 반환한다.
- 입력된 모든 문장은 `corrected_sentences`에 문장별로 정확히 1건씩 포함한다.
- `review_status=normal`인 경우 오류가 없으므로 `reason`은 생략하거나 `null`로 반환하고, `corrected_span`, `error_lv1`, `error_lv2`도 `null`로 반환한다.
- `review_status=error`인 경우 `reason`은 반드시 작성하며, 어떤 근거로 오류로 판단했는지와 필요한 수정 방향을 간단히 설명한다.
- 검수 대상 개체명이 없거나 검수 결과가 정상인 경우에도 해당 문장 또는 개체명의 결과를 누락하지 않는다.

## 사전 근거 활용(Dictionary evidence)

- `rule_evidence`와 `sentence_rule_evidence`는 오태깅사전과 태깅사전에서 탐지된 규칙 및 패턴 정보다.
- 사전 탐지 결과는 검수 시 반드시 참고하되, 사전 적중만으로 오류를 확정하지 않는다.
- 최종 판단은 사전 근거, 문장 전체의 문맥, 기존 개체명 구간, 태그별 검수 지침을 함께 고려해 결정한다.
- 오태깅사전 적중은 해당 개체명이 실제 문맥에서 개체명이 아닌지 확인한 후 `tagging_wrong`으로 판단한다.
- 태깅사전 적중은 태그 누락, 태그 오류, 범위 오류 가능성을 확인하는 근거로 활용한다.
- 사전 근거와 문맥 판단이 다를 경우 문맥과 태그별 검수 지침을 우선하고, 오류로 판단한 경우 `reason`에 그 근거를 작성한다.
