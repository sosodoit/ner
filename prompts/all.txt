역할: 한국어 개체명 태깅 검수의 공통 판단 기준

## 1. 태그 체계

- `PS`: 인명
- `LC`: 지명·장소
- `OG`: 기관·단체
- `AF`: 인공물
- `DT`: 날짜·시점
- `EV`: 사건·사고·행사

## 2. 개체명 정의

현실 세계의 특정 개인·장소·기관·인공물·시점·사건을 다른 대상과 구별하여 지칭하는 표현. 보통명사도 문맥상 특정 대상을 지칭하면 개체명으로 인정.

특정 대상을 지칭하지 않는 일반 명사, 단순 유형·수량·직책·기능 설명은 미태깅.

## 3. 공통 판단 순서

1. 문맥에서 특정 대상을 지칭하는지 판별
2. 개체명인 경우 명칭의 전체 범위 확인
3. 최장 단위 태깅 원칙 적용
4. 명시된 최소 단위 태깅 예외 확인
5. 문맥과 서술어로 실제 지칭 대상 및 태그 결정
6. 하나의 대상에 하나의 태그만 부여

## 4. 명칭 범위

하나의 대상을 지칭하는 명사·명사구는 가능한 한 하나의 개체로 처리.

앞부분을 제거하면 뒤 표현만으로 같은 대상이 특정되는지 확인.

- 특정 불가: 앞부분을 명칭에 포함
- 특정 가능: 소재지·소속·부연 설명으로 보고 분리

복합 명칭의 태그는 핵 명사가 지칭하는 대상의 성질로 결정. 앞부분이 날짜·인명이라는 이유만으로 `DT`·`PS` 부여 금지.

- `12·3 비상계엄` → `<12·3 비상계엄: EV>`
- `조은석 내란 특검팀` → `<조은석 내란 특검팀: OG>`
- `김대중도서관` → `<김대중도서관: OG>`

단독 시점으로 성립하는 날짜·기간은 사건명·행사명과 분리. `년·월·일` 단위어가 있거나 단독 시점이 성립하면 `DT`로 처리.

- `<지난해 12월 3~4일: DT>` `<불법계엄: EV>`
- `<12·3 비상계엄: EV>`

## 5. 최소 단위 태깅 예외

아래 목록에 해당하는 경우에만 최장 단위 원칙의 예외 적용. 목록에 없는 결합 형태는 최장 단위 원칙 적용.

1. 연속한 지역명: `대전 유성구 신성동` → `<대전: LC>` `<유성구: LC>` `<신성동: LC>`
2. 지역명+건축물: `잠실 롯데월드타워` → `<잠실: LC>` `<롯데월드타워: AF>`
3. 지역명+기관: `미국 컬럼비아대학` → `<미국: LC>` `<컬럼비아대학: OG>`
4. 행사명 앞 회차·날짜: `제24회 서울올림픽경기` → `제24회` `<서울올림픽경기: EV>`
5. 비공식 명사구: 공식·관용 명칭이 아닌 경우 고유명 부분만 태깅
6. 호칭·직책: 인명과 분리하고 직책 자체는 미태깅

지명이 기관명의 일부로 굳어진 경우 기관 전체를 `OG`로 통합. 인명 뒤 `정부·내각·행정부·정권`은 `PS`와 분리하여 `OG` 기준 적용. 인명 뒤 기관성 명사가 하나의 기관명칭을 이루면 통합.

## 6. 범주 판단

형태보다 문장의 의미, 서술어, 주변 문맥 우선 적용.

- 물리적 구조물·작품·상품 → `AF`
- 조직·행위 주체·기관 → `OG`
- 지역·장소·지형·천체 → `LC`
- 시간적 기준·범위 → `DT`
- 발생·개최·수행된 구체적 사건·행사 → `EV`
- 특정 인물·캐릭터·반려동물 → `PS`

동일 표현이 여러 범주로 해석되면 실제 지칭 대상과 서술어로 하나의 범주 선택. 태그 중첩 및 복수 태그 부여 금지.

## 7. 규칙 충돌 우선순위

1. 입력 문맥과 실제 지칭 대상
2. 개체명 여부
3. 명시된 예외 규칙
4. 최장 단위 태깅
5. 태그별 포함·제외 기준
6. 태그별 대표 사례의 유추 적용

상위 우선순위와 하위 우선순위가 충돌하면 상위 기준 적용. 명시된 예외가 없는 경우 최장 단위 원칙 적용.

## 8. 적용 범위

이 문서는 공통 판단 기준만 정의. 입력 해석, 검수 절차, 불확실 사례 처리, 출력 필드와 JSON 형식은 `system_prompt.txt` 및 `ner_reviewer.py` 기준 적용.
