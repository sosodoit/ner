# 괄호 표기 처리

## 적용 조건
개체명과 함께 괄호가 나타난 경우. 괄호 안 내용은 원어, 영문, 한자, 약칭, 별칭, 부가 정보 등.

## 1단계. 괄호 위치 판단

| 위치 | 판단 | 처리 |
|---|---|---|
| 개체명 중간 (괄호 뒤 문자열도 명칭의 일부) | 통합 | 괄호 포함 전체를 하나로 태깅. 괄호 안 별도 태깅 금지 |
| 개체명 끝 (괄호 전까지 완결된 명칭) | 분리 | 앞 개체명은 괄호 앞에서 닫고, 괄호 안은 2단계로 판단 |

- 통합: 퓨(Pew)공익재단의 → `<퓨(Pew)공익재단: OG>`의 / 톄링(鐵嶺)시 → `<톄링(鐵嶺)시: LC>`
- 통합 오답: `<퓨(<Pew: OG>)공익재단: OG>` (중첩 금지)

## 2단계. 분리된 괄호 안 판단

| 괄호 안 내용 | 처리 | 예시 |
|---|---|---|
| 앞 개체와 같은 대상의 다른 표기 (원어, 한자, 영문, 약칭, 별칭, 활동명) | 앞 개체와 같은 태그 | `<방탄소년단: PS>`(`<BTS: PS>`) / `<국가수사본부: OG>`(`<국수본: OG>`) / `<수월관음도: AF>`(`<水月觀音圖: AF>`) |
| 다른 개체 (국적, 소속, 소재지, 작품, 소속팀) | 해당 개체 자체의 범주 | `<봉준호: PS>`(`<기생충: AF>`) / `<손흥민: PS>`(`<토트넘: OG>`) |
| 설명 정보 (나이, 순위, 직책, 수치, 성별, 업무 설명) | 미태깅 | `<김철수: PS>`(45) / `<국토교통부: OG>`(4대강 사업 담당) |
| 명칭에 붙는 접미 조각 (誌, 號, 氏, 君) | 미태깅 | `<이코노미스트지: OG>`(誌) / `<윤덕여호: OG>`(號) |
| 6개 태그 밖 범주 | 미태깅 | — |

여러 항목이 나열되면 항목별로 판단: 샤라포바(러시아, 2위, 28세) → `<샤라포바: PS>`(`<러시아: LC>`, 2위, 28세)

## 범위 원칙

- 분리 시 괄호 기호 `(` `)`는 태그 밖
- '이하', '약칭', '구', '현', '옛' 등 관계 표시어는 태그 밖: `<한국문화예술위원회: OG>`(이하 `<문예위: OG>`)
- 괄호 뒤 조사는 태그 밖: `<투어스: PS>`(`<TWS: PS>`)가
- 같은 대상의 두 표기도 각각 별도 태깅. 하나로 합치지 않음
- 괄호 안이 다른 대상이면 앞 개체의 태그를 따르지 않음. 태그를 맞추기 위해 어느 쪽도 변경하지 않음

## 검수 확인 사항

1. 괄호를 포함한 태그 범위가 통합 대상인지 (개체명 중간 괄호인지)
2. 태그 중첩 여부 (`<A(<B: X>): Y>` 형태)
3. 괄호 안 같은 대상의 다른 표기가 미태깅으로 남았는지 → 태깅 누락
4. 괄호 안 태그가 앞 개체와 같을 때 실제로 같은 대상인지
5. 관계 표시어·설명 정보·괄호 기호가 태그 범위에 들어갔는지 → 범위 오류

괄호 안 개체명을 기사 전체에서 일괄 태깅하라는 의미가 아님. 기존 태깅의 오류 확인 기준.
