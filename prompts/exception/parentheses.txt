# 괄호 표기 처리

## 적용 조건
개체명과 함께 괄호가 나타난 경우. 괄호 내용은 원어, 영문 표기, 한자, 약칭, 별칭, 부가 정보 등을 포함할 수 있음.

## 판단 절차

### 1단계. 괄호 위치 판단
- 괄호가 개체명 중간에 있고, 괄호 뒤 표현도 개체명의 일부인 경우: 괄호를 포함한 전체 표현을 하나의 태그로 통합
- 괄호가 완결된 개체명 뒤에 이어지는 경우: 앞 개체명과 괄호 안 표현을 분리하여 각각 판단

### 2단계. 분리된 괄호 내용 판단
- 앞 개체명과 같은 대상을 가리키는 다른 표기(원어, 한자, 영문, 로마자, 약칭, 별칭, 활동명): 앞 개체명과 동일한 태그 부여
- 다른 개체명(국적, 소속 기관, 소재지, 작품명, 소속팀 등): 해당 개체 자체의 범주로 태깅
- 개체명이 아닌 설명 정보(나이, 순위, 직책, 수치, 날짜, 성별): 미태깅
- 개체명의 일부가 아닌 접미사·단위어 조각(誌, 氏, 君, 山 등): 미태깅
- 괄호 안이 현재 태깅 대상에 해당하지 않는 경우: 태그 없이 유지

### 3단계. 괄호 안에 여러 항목이 나열된 경우
항목별로 2단계 기준 적용

## 원칙
- 괄호 기호 `(`, `)`는 분리 판정 시 태그 밖에 배치
- 괄호가 개체명 중간에 포함되어 통합 판정된 경우에만 괄호를 태그 안에 포함
- 태그 중첩 금지. 분리 판정 시 앞 개체명의 태그를 괄호 앞에서 닫고, 괄호 안에 별도 태그 부여
- 통합 판정 시 괄호 안에 별도 태그를 부여하지 않음
- 앞 개체명과 괄호 안 표기가 같은 대상을 가리켜도 각각 별도 태깅. 하나로 합치지 않음
- 괄호 안 표기가 앞 개체명과 같은 대상을 가리키는 경우에만 앞 개체명의 태그 적용
- 괄호 안 표기가 다른 대상을 가리키는 경우 앞 개체명의 태그를 따르지 않고 해당 대상 자체의 범주로 판단
- 두 표현의 범주가 다르면 각각의 판단 유지. 태그 일치를 위해 어느 한쪽의 태그를 변경하지 않음
- 괄호 안의 ‘이하’, ‘약칭’, ‘구’, ‘현’, ‘옛’ 등 관계 표현은 태그 범위에서 제외
- 괄호 뒤에 조사가 이어지는 경우 조사는 태그 밖에 배치

## 예시

### 분리: 같은 대상의 다른 표기
- 투어스(TWS)가 데뷔했다 → `<투어스: PS>`(`<TWS: PS>`)가 데뷔했다
- 방탄소년단(BTS) → `<방탄소년단: PS>`(`<BTS: PS>`)
- 수월관음도(水月觀音圖) → `<수월관음도: AF>`(`<水月觀音圖: AF>`)
- 국가수사본부(국수본) → `<국가수사본부: OG>`(`<국수본: OG>`)
- 한국문화예술위원회(이하 문예위) → `<한국문화예술위원회: OG>`(이하 `<문예위: OG>`)

### 분리: 다른 대상
- 봉준호(기생충) → `<봉준호: PS>`(`<기생충: AF>`)
- 손흥민(토트넘) → `<손흥민: PS>`(`<토트넘: OG>`)
- 아이브(스타쉽엔터테인먼트) → `<아이브: PS>`(`<스타쉽엔터테인먼트: OG>`)
- 샤라포바(러시아, 2위, 28세) → `<샤라포바: PS>`(`<러시아: LC>`, 2위, 28세)

### 분리: 괄호 안이 미태깅 대상
- 김철수(45)는 → `<김철수: PS>`(45)는
- 이코노미스트지(誌)는 → `<이코노미스트지: OG>`(誌)는
- 국토교통부(4대강 사업 담당) → `<국토교통부: OG>`(4대강 사업 담당)

### 통합: 괄호 안은 별도 태깅하지 않음
- 퓨(Pew)공익재단의 
  → `<퓨(Pew)공익재단: OG>`의
  ※ `<퓨(<Pew: OG>)공익재단: OG>` 형태 금지
- 톄링(鐵嶺)시 → `<톄링(鐵嶺)시: LC>`

## 미태깅 대상
- 괄호 안이 설명 정보(나이, 순위, 직책, 수치, 날짜, 성별)뿐인 경우
- 괄호 안이 접미사·단위어 조각(誌, 氏, 君 등)인 경우
- 괄호 안이 현재 태깅 대상에 해당하지 않는 경우

## 검수 시 확인 사항
1. 기존 태그 범위에 괄호가 포함된 경우, 괄호가 개체명 중간에 포함되어야 하는지 확인
2. 태그 중첩 여부 확인. `<A(<B: X>): Y>` 형태 금지
3. 괄호 안의 다른 표기가 태깅되지 않은 경우, 동일 대상을 가리키는지 확인 후 누락 여부 판단
4. 괄호 안 태그가 앞 개체명과 같은 경우에도 실제로 같은 대상을 가리키는지 확인
5. 통합 대상 표현 안에 별도 태그가 중첩되어 있는지 확인
6. ‘이하’, ‘약칭’, ‘구’, ‘현’, ‘옛’ 등이 태그 범위에 포함되었는지 확인

※ 검수 항목은 기존 태깅 오류 확인 기준이며, 기사 전체를 새로 태깅하거나 괄호 표현을 일괄 태깅하라는 의미가 아님.
