# LLM_E001 판단 기준: 오태깅

## 판정 대상
기존 태그 <X: T>에서 X가 이 문맥에서 특정 대상을 다른 대상과 구별하여 지칭하는지, 태깅 제외 대상인지 판단한다.

## TRUE 조건
검수 대상 문장에 포함된 기존 태깅 중 다음에 해당하는 개체명이 하나 이상 존재하면 TRUE.

1. 일반명사, 유형어, 수량, 기능 설명. 단, 하위 태그 판단표에서 보통명사 허용 대상으로 표시된 유형은 제외한다.
2. 6개 태그 밖 범주
   - 직위·직업·호칭
   - 회차·수량, 시각·시간대
   - 법률·제도·정책·사업, 상·훈장
   - IT 서비스·SW·HW·모델 일련번호
   - 언어, 국민·민족(한국인), 음식·의류
3. 상위어·보통명사 재지칭(대학교 측, 위원회, 시, 본부, 이번 대회)
4. 복합어 내부 요소(경찰차의 경찰, 한국적의 한국)
5. 익명 이니셜(A씨), 가문 성씨, 반복 주기(매일·매년), 가상 장소, OO바위
6. 4대강, 제도 일반을 뜻하는 '계엄', 선거 일반론(역대 대선)
7. 하위 태그 판단표의 제외 대상 열에 해당하는 표현

## FALSE 조건
- 표현이 문맥상 특정 대상을 지칭하는 경우
- 보통명사 허용 대상으로 표시된 하위 태그에 해당하는 경우

## 구분 원칙
- 태깅 대상 자체가 아닌지 판단한다.
- 태깅 대상은 맞지만 대분류가 잘못된 경우는 LLM_E002에서 판단한다.
- 태그 범위의 시작·끝이 잘못된 경우는 LLM_E003에서 판단한다.

# LLM_E002 판단 기준: 태그 오류

## 판정 대상
기존 태그 <X: T>에서 X의 실제 지칭 대상이 부착된 태그 T와 다른 대분류에 속하는지 판단한다.

## 판단 절차
1. 기사 전체 문맥에서 X가 실제로 지칭하는 대상을 확정한다.
2. 하위 태그 판단표의 정의와 대표 예시를 참고하여 적절한 하위 유형을 검토한다.
3. 하위 태그 판단표의 경합 태그와 아래 경합 쌍 판단 기준을 확인한다.
4. 실제 지칭 대상의 대분류와 기존 태그의 대분류를 비교한다.

## 경합 태그 판단 기준
- PS ↔ AF: 작품명은 AF, 등장인물은 PS. 인간문화재 문맥의 실명은 AF.
- PS ↔ OG: 음악 그룹은 PS, 소속사·상설 예술단체·스포츠팀·범죄 조직은 OG.
- LC ↔ OG: 국가·지자체가 행위 주체, 협상 당사자, 경기 상대, '~측'이면 OG. 소재지·배경·수식어이면 LC. 왕조·시대 의미이면 DT.
- LC ↔ AF: 도로·보·전망대·문화재 마을은 AF. 위치를 나타내는 사거리, 비지정 유적·마을은 LC.
- OG ↔ AF ↔ LC: 공연장·백화점·박물관은 운영·제작이면 OG, 짓다·보이다이면 AF, 만나다이면 LC. 개별 상점은 OG. 신문은 보도 의미이면 OG, 읽는 대상 의미이면 AF. 군함은 조직 의미이면 OG, 함선 의미이면 AF.
- OG ↔ EV: 리그는 소속·출범 의미이면 OG, 개최·시즌·우승 의미이면 EV.
- DT ↔ EV: 가운뎃점 날짜가 붙은 사건명은 EV. 사건명+'때'는 DT. 공휴일·기념일은 DT. 기념 행사명은 EV.
- AF ↔ EV: 조약은 체결 사건 의미이면 EV. 공연 작품은 AF, 공연 행사는 EV.

## TRUE 조건
실제 지칭 대상의 대분류가 기존 태그의 대분류와 다른 경우 TRUE.

## FALSE 조건
- 실제 지칭 대상이 기존 태그의 대분류에 부합하는 경우
- 같은 대분류 안에서 하위 태그만 다른 경우

## 구분 원칙
- 하위 태그는 대분류 판단의 근거로 활용하되, 하위 태그 차이만으로 TRUE 처리하지 않는다.
- 태깅 대상 자체가 아닌 경우는 LLM_E001 기준과 구분한다.
- 대분류 간 경합은 단어의 표면형이 아니라 문맥상 실제 지칭 대상에 따라 판단한다.

# LLM_E003 판단 기준: 범위 오류

## 판정 대상
기존 태그 X의 범위에 불필요한 문자열이 포함되었거나, 명칭을 구성하는 문자열이 누락되었거나, 서로 다른 개체명이 하나의 태그로 묶였는지 판단한다.

## TRUE 조건
검수 대상 문장에 포함된 기존 태그 중 다음 범위 오류가 하나 이상 확인되면 TRUE.

### 1. 범위축소
태그 내부에 다음 표현이 포함되어 범위를 줄여야 하는 경우.
- 조사, 직위·호칭, 미스·미스터
- 회차(제N회, 제21대), 전·해당·이번·산하·소속·당시
- 대비·연속·이상·이하·보다
- 시각·시간대, 지정 등급(국보 제N호)
- 괄호 기호와 괄호 안 관계어(이하, 약칭)
- 행사명 앞뒤의 독립 연도
- 학과·사무처·객실명
- 하위 태그 판단표의 해당 하위 태그 '제외 대상'에 해당하는 표현이 다른 개체명의 태그 범위 안에 포함된 경우

제외 대상 여부는 현재 태그에 적합한 하위 태그를 기준으로 확인한다. 단순히 제외 대상과 유사한 문자열이 있다는 이유만으로 범위축소 처리하지 않는다.

### 2. 범위확장
태그 밖으로 다음 표현이 빠져 범위를 넓혀야 하는 경우.
- 명칭으로 굳어진 지명·인명·사건명(광주교육청, 조은석 내란 특검팀, 김대중도서관)
- 가운뎃점 날짜(12·3 비상계엄), 인명 접미사 '-이'(영숙이)
- 날짜에 붙는 부터·까지·이후·만·간·쯤·초·말, '지난/오는'+날짜
- 지점·캠퍼스명, 상품의 모델·버전명, 도로의 'n길', 대회 단계(4강)
- 행사명 중간의 연도

### 3. 태깅분리
하나의 태그 안에 다음과 같이 서로 다른 개체명이 묶여 각각 분리해야 하는 경우.
- 연속 지역명, 지역명+건축물, 소재지+기관, 인명+정부
- 날짜+요일, 날짜+시각, 대등 나열
- 비공식 명칭(서울 올림픽공원 체조경기장), 브랜드+상품명, 커플명
- 괄호 안의 다른 표기
- 중첩 태그(<A(<B: X>): Y>)

## FALSE 조건
- 기존 태그 범위가 명칭의 구성 범위와 일치하는 경우
- 포함된 문자열이 해당 개체명의 정식 명칭에 포함되는 경우
- 인접한 표현이 별개의 개체명이 아니라 하나의 정식 명칭을 구성하는 경우

## 구분 원칙
- 실제 원문과 기존 태그의 시작·끝 범위를 비교한다.
- 표현이 길거나 짧다는 이유만으로 오류 처리하지 않는다.
- 범위축소, 범위확장, 태깅분리를 구분한다.
- 서로 다른 태그 사이의 병합 필요 여부는 LLM_S001에서 판단한다.

# LLM_S001 판단 기준: 태깅 병합

## 판정 대상
문장 안에서 서로 인접한 둘 이상의 태그가 하나의 개체명을 나누어 태깅했는지 판단한다.

## TRUE 조건
인접 태그를 하나의 태그로 병합해야 하는 경우.
- 연+월+일
- 지난해+날짜
- 날짜 범위(3일부터 5일까지)
- 상위 기관+독립 하위 기관(경찰청 국가수사본부)
- 명칭으로 굳어진 인명·사건명+기관(조은석 내란 특검팀)
- 호+이름(퇴계 이황)
- 정식 명칭인 건축물·시설(잠원 한강공원 수영장)
- 상호+지점명(스타벅스 홍대점)
- 가운뎃점 날짜+사건명

## FALSE 조건
- 인접한 태그가 서로 다른 개체명을 지칭하는 경우
- 각 태그가 독립적으로 완결된 개체명인 경우
- 병합하면 서로 다른 개체명이 하나로 합쳐지는 경우

## 구분 원칙
- 단순히 인접해 있다는 이유만으로 병합하지 않는다.
- 인접 태그 전체가 하나의 명칭을 구성하는지 문맥과 정식 명칭 기준으로 판단한다.
- 기존 태그 내부의 범위 오류는 LLM_E003과 구분한다.
