# 하위 태그 판단표

## 용도 및 적용 방법
- LLM_E001: 보통명사 허용 여부와 제외 대상 확인
- LLM_E002: 대분류에 부합하는 하위 태그 후보, 정의 및 경합 태그 확인
- LLM_E003: 다른 개체명의 태그 범위 안에 포함된 제외 대상 표현 확인
- 보통명사 허용 표시가 있는 하위 태그는 고유명이 아닌 유형 명칭도 태깅 대상
- 보통명사 허용 표시가 없는 하위 태그는 고유명 또는 문맥상 특정 대상을 지칭하는 명칭만 태깅 대상
- 제외 대상 표현이 단독으로 태깅되어 있으면 LLM_E001 TRUE, 다른 개체명의 태그 범위 안에 포함되어 있으면 LLM_E003 범위축소 TRUE
- 대분류 판정 후 정의에 부합하는 하위 태그 1개를 내부적으로 선택
- 어떤 하위 태그에도 부합하지 않으면 대분류 재판정 또는 LLM_E001 재검토
- 하위 태그는 내부 판단에만 사용하고 최종 결과로 출력하지 않음
- 경합 태그의 괄호 안 조건은 해당 문맥에서 경합 태그로 판단하는 조건
- '-'는 별도 경합 태그 또는 제외 대상이 없음을 의미
