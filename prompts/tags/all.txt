# 개체명 태깅 검수 공통 기준

## 1. 태그 체계

| 태그 | 대상 | 하위 유형 (판단용, 출력하지 않음) |
|---|---|---|
| `PS` | 인물 | 인명, 캐릭터, 반려동물 |
| `LC` | 장소·지리 | 국가, 도·주, 세부 행정구역, 도시, 수도, 강·호수, 바다, 반도·만, 산, 섬, 대륙, 천체, 기타 장소 |
| `OG` | 기관·단체 | 경제, 교육, 군사, 미디어, 스포츠, 예술, 의료, 종교, 과학, 도서관, 법률, 정부·정치, 음식 업체, 숙박 업체, 기타 기관·단체 |
| `AF` | 인공물 | 건축물, 문화재, 길, 운송 수단, 악기, 무기, 예술 작품(문헌·공연·영상·미술·음악), 상품(서비스 상품·공산품) |
| `DT` | 날짜·기간 | 기간, 일, 주, 월, 연도, 계절, 지질시대, 왕조·역사 시대, 복합 날짜 |
| `EV` | 사건·행사 | 사회운동·선언, 전쟁·혁명, 스포츠 행사, 축제, 기타 사건·사고·행사 |

### 6개 태그 밖 범주: 태깅 대상 아님

원 지침의 아래 범주는 이 프로젝트의 태깅 대상이 아님. 해당 표현은 미태깅이 정상이며 누락으로 판정하지 않음.

| 범주 | 대표 표현 |
|---|---|
| 시간(TI) | 3시, 오후, 새벽, 2시간, 30분 |
| 수량(QT) | 제24회, 21대, 2위, 45세, 1일차, 8년차, 주소 번지 |
| 문명(CV) | 대통령·장관 등 직책, 기자·경찰관 등 직업, 법률·정책·제도, 상·훈장, 화폐, 음식, 의복, 민족, 언어 |
| 학문·이론·동식물·물질·용어(FD·TR·AM·PT·MT·TM) | 경제학, 상대성이론, 고양이, 시금치, 산소, 스마트폰·노트북 등 정보기기 일반명 |

같은 표현이 문맥에 따라 6개 태그 중 하나로 쓰이면 태깅 대상 (예: 경찰 = 기관이면 `OG`, 직업이면 미태깅).

## 2. 개체명 정의

현실 세계의 특정 대상을 다른 대상과 구별하여 지칭하는 명사·명사구.

- 고유명: 태깅 대상
- 보통명사: 태그 문서가 허용한 경우만 태깅 대상 (예: `AF`의 악기·무기·운송 수단 종류명, `EV`의 문맥상 하나로 특정되는 행사명, `DT`의 오늘·주말 등 시간 표현, `OG`의 정부·검찰·경찰 등 기관 통칭)
- 미태깅: 특정 대상을 지칭하지 않는 일반 명사, 단순 유형·수량·직책·기능 설명, 상위어·보통명사에 의한 재지칭

## 3. 판단 순서

1. 문맥에서 특정 대상을 지칭하는지 판별
2. 지칭 대상이 6개 태그 중 무엇인지 결정
3. 명칭 전체 범위 확인: 최장 단위 원칙 적용
4. 4.2의 최소 단위 예외 해당 여부 확인
5. 하나의 대상에 하나의 태그만 부여 (유일 태깅 원칙)

## 4. 태깅 단위

### 4.1. 최장 단위 원칙

하나의 대상을 지칭하는 명사구는 전체를 하나의 개체명으로 태깅.

판단 테스트: 앞부분을 떼어도 뒷부분만으로 같은 대상이 특정되는가?

- 특정되지 않음 → 앞부분이 명칭의 일부 → 통합
- 특정됨 → 앞부분은 소재지·소속·부연 설명 → 분리

| 원문 | 정답 | 근거 |
|---|---|---|
| 한국해양대학 | `<한국해양대학: OG>` | 지명이 기관명의 일부 |
| 스페인 대사관 | `<스페인 대사관: OG>` | 대사관이 위치한 곳이 아닌, 스페인의 대사관 |
| 경찰청 야구단 | `<경찰청 야구단: OG>` | 전체가 하나의 스포츠팀 |
| 콩순이 말하는 냉장고 | `<콩순이 말하는 냉장고: AF>` | 캐릭터명이 상품명의 일부 |
| 스타벅스 대학로점 | `<스타벅스 대학로점: OG>` | 지점명만으로 어느 업체인지 특정 불가 |
| 현대오일뱅크 대산공장 | `<현대오일뱅크 대산공장: LC>` | 공장명만으로 특정 불가 |
| 88 서울 올림픽 경기 | `<88 서울 올림픽 경기: EV>` | '88'만으로는 연도 불성립 |
| 12·3 비상계엄 | `<12·3 비상계엄: EV>` | 가운뎃점 날짜가 사건명의 일부 |
| 조은석 내란 특검팀 | `<조은석 내란 특검팀: OG>` | 인명·사건명이 기관 호칭의 일부 |

복합 명칭의 태그는 핵 명사가 지칭하는 대상의 성질로 결정. 앞부분이 인명·지명·날짜라는 이유만으로 `PS`·`LC`·`DT` 부여 금지.

### 4.2. 최소 단위 예외

아래 목록에 해당하는 경우에만 분리 태깅. 목록에 없는 결합은 최장 단위 원칙 적용.

| 결합 유형 | 원문 | 정답 |
|---|---|---|
| 지역명 + 지역명 | 대전 유성구 신성동 | `<대전: LC>` `<유성구: LC>` `<신성동: LC>` |
| 지역명 + 건축물 | 잠실 롯데월드타워 | `<잠실: LC>` `<롯데월드타워: AF>` |
| 지역명 + 소재 기관 | 미국 컬럼비아대학 | `<미국: LC>` `<컬럼비아대학: OG>` |
| 국가 + 기관 + 기관 | 대한제국 법부 전라북도재판소 | `<대한제국: LC>` `<법부: OG>` `<전라북도재판소: OG>` |
| 국가·인명 + 정부 | 한국 정부 / 이명박 정부 | `<한국: LC>` `<정부: OG>` / `<이명박: PS>` `<정부: OG>` |
| 회차 + 행사·상 | 제24회 서울올림픽경기 | 제24회 `<서울올림픽경기: EV>` |
| 날짜 + 행사 | 1988년 서울 올림픽 경기 | `<1988년: DT>` `<서울 올림픽 경기: EV>` |
| 날짜 + 요일 / N주 + 요일 | 12월 4일 금요일 / 셋째 주 수요일 | `<12월 4일: DT>` `<금요일: DT>` / `<셋째 주: DT>` `<수요일: DT>` |
| 인명 + 직책 | 문재인 대통령 | `<문재인: PS>` 대통령 |
| 비공식 명사구 | 광주 돔구장 / 서울 올림픽공원 체조경기장 | `<광주: LC>` 돔구장 / `<서울: LC>` `<올림픽공원: LC>` 체조경기장 |

### 4.3. 복합어 내부

복합어(합성어·파생어) 전체가 개체명일 때만 태깅. 내부 요소는 개체명이어도 따로 태깅하지 않음.

- 한국적 문화 / 한국인 / 경찰차 / 야구장 → 내부의 한국·경찰 미태깅
- 국어국문학과 → 대학 하위 부서이므로 미태깅

### 4.4. 조사·어미

조사는 태그 밖에 배치. 단, `DT`의 범위·경과 표지(부터, 까지, 만 등)는 `dt.txt` 기준.

## 5. 범주 결정

### 5.1. 문맥 우선

형태보다 문장의 의미, 서술어, 공기 명사 우선. 서술어도 다의적이므로 서술어 하나만으로 확정하지 않고 개체의 본래 의미와 문장 전체를 함께 고려.

| 지칭 대상 | 태그 | 대표 서술어·단서 |
|---|---|---|
| 특정 인물·캐릭터·반려동물 | `PS` | 말하다, 수상하다, 태어나다 |
| 위치·지역·지형·천체 | `LC` | ~에 있다, ~로 가다, 흐르다, 위치하다 |
| 조직·행위 주체 | `OG` | 발표하다, 운영하다, 결정하다, 수사하다, 경영하다 |
| 물리적 구조물·작품·상품 | `AF` | 짓다, 보이다, 무너지다, 읽다, 연주하다, 타다 |
| 시간적 기준·범위 | `DT` | ~에, ~부터, ~동안 |
| 발생·개최·수행된 사건·행사 | `EV` | 열리다, 개최하다, 발생하다, 치르다, 우승하다 |

### 5.2. 문맥으로 결정할 수 없을 때의 우선 태그

| 예 | 우선 태그 | 대안 태그 |
|---|---|---|
| 한국, 프랑스 (국가명) | `LC` | `OG` |
| 고양시, 성남시 (도시명) | `LC` | `OG` |
| 청와대, 국립중앙박물관 (기관 겸 건물) | `OG` | `AF` |
| 미아사거리 (도로 겸 위치) | `AF` | `LC` |
| 군함 이름 (기관 겸 함선) | `AF` | `OG` |
| 조약·협정 (사건 겸 문서) | `EV` | 미태깅 |
| 국가명 (국가 겸 언어·버전) | `LC` | 미태깅 |

우선 태그는 문맥 판단이 불가능할 때만 사용. 우선 태그를 적용한 판정은 `review_needed: true` 후보.

## 6. 유일 태깅 원칙

하나의 개체에 하나의 태그만 부여. 태그 중첩 및 복수 태그 금지.

## 7. 규칙 충돌 시 우선순위

1. 입력 문맥과 실제 지칭 대상
2. 개체명 여부 (특정 대상 지칭, 6개 태그 범주 해당)
3. 태그 문서에 명시된 예외 규칙
4. 최장 단위 원칙
5. 태그별 포함·제외 기준
6. 태그별 예시의 유추 적용

상위 기준과 하위 기준이 충돌하면 상위 기준 적용. 명시된 예외가 없으면 최장 단위 원칙 적용. 어느 조항으로도 결론이 나지 않으면 판단 유보.

## 8. 적용 범위

이 문서는 공통 판단 기준만 정의. 입력 해석, 검수 절차, 결과 분류, 출력 형식은 `system_prompt.txt`와 `schema.py` 기준.
