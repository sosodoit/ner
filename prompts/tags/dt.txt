# 태그별 검수 기준: DT (날짜·기간)

## 1. 정의
날짜, 기간, 요일, 주, 월, 연도, 계절, 지질시대, 왕조·역사 시대 등 일(日) 이상 단위의 시간적 기준이나 범위를 나타내는 표현. 정확한 수치를 알 수 없어도 문맥상 시간적 기준·범위를 제공하면 태깅 (수년 전, 몇 달 동안).

시·분·초, 하루 안의 시간대(TI)는 태깅 대상 아님.

## 2. 하위 유형

| 하위 유형 | 태깅 대상 | 예시 |
|---|---|---|
| 기간 | 지속 기간, '~부터 ~까지', 시기 구간, N박 N일, 시즌, 경과의 '~째' | 3일간, 수십 년간, 2006년부터 2016년까지, 성수기, 방학(특정 시기), 하루, 일주일, 1박 2일, 연말, 포스트시즌, 3일째(동안) |
| 일 | 날짜, 요일, 평일·주말·공휴일, 절기, 명절·법정 기념일, 상대적 날짜, 특정일 관용어 | 10일, 금요일, 입춘, 설날, 어버이날, 지구의 날, 오늘, 이날, 전날, 불금 |
| 주 | 상대적 주, 주차 | 이번 주, 지난주, 차주, 둘째 주 |
| 월 | 월, 상대적 월, 특정 달 지칭 명칭 | 9월, 이달, 익월, 가정의 달 |
| 연도 | 연도, 연대, 상대적 연도, '~년생', 간지 연도, 연호 + 연도 | 2024년, 90년대, 올해, 전년, 85년생, 을미년, 쥐띠 해, 영락 1년 |
| 계절 | 계절, '~철', 계절 한자어 | 봄, 여름철, 하계 |
| 지질시대 | 지질·선사시대 명칭 | 캄브리아기, 중생대, 청동기시대 |
| 왕조·역사 시대 | 왕조, 왕의 재위 시기, 역사 시대, 세기 | 고려시대, 일제강점기, 구한말, 고대, 중세, 성종 때, 19세기 |
| 복합 날짜 | 년+월+일, 년+월, 월+일, 상대 시점, 사건 기준 시점 | 2024년 12월 3일, 지난해 12월, 3일 전, 한일 월드컵 때 |

## 3. 통합 원칙

인접한 날짜 표현이 함께 하나의 시점·기간을 가리키면 전체를 하나의 `DT`로 태깅. 판단 기준: 뒤 표현이 앞 표현의 범위를 좁히는가 (연 → 월 → 주 → 일).

- `<지난해 12월 3일: DT>` / `<올해 5월: DT>` / `<이달 15일: DT>` / `<내년 3월 초: DT>` / `<지난달 셋째 주: DT>` / `<전년 같은 기간: DT>` / `<지난해 겨울: DT>` / `<이번 주말: DT>`
- '지난', '오는'이 날짜와 결합하면 함께 태깅: `<오는 4일: DT>` / `<지난 2014년 10월: DT>`
- 띄어쓰기 여부는 판단에 영향 없음: 수십년간 = 수십 년간

## 4. 분리 지점

아래 다섯 경우에만 분리. 그 밖은 통합이 기본값.

| 분리 지점 | 예시 |
|---|---|
| 1. 요일이 이어질 때 (날짜 + 요일, N주 + 요일) | `<12월 4일: DT>` `<금요일: DT>` / `<셋째 주: DT>` `<수요일: DT>` / `<9월 첫째 주: DT>` `<화요일: DT>` / `<이번 주: DT>` `<금요일: DT>` |
| 2. 시각·시간대·시간 단위가 이어질 때 | `<12월 3일: DT>` 오후 3시 / `<오늘: DT>` 밤 / `<3일: DT>` 5시 출발 |
| 3. 뒤 표현이 독립된 다른 개체명일 때 | `<지난 2002년: DT>` `<한일 월드컵 때: DT>` / `<1988년: DT>` `<서울 올림픽 경기: EV>` |
| 4. 조사·접속어·쉼표로 대등하게 나열될 때 | `<지난해: DT>`와 `<올해: DT>` |
| 5. 뒤 표현이 앞 표현의 하위 구간이 아닐 때 | `<어제: DT>` `<오늘: DT>` 이틀간 |

괄호 속 요일 약어도 요일로 `DT`: `<10월 31일: DT>`(`<금: DT>`). 단, 물결표 기간 안에 괄호 요일이 들어간 경우 기간 전체를 하나로: `<2020.1.13(수)~2020.2.15(금): DT>`.

## 5. 결합 표현의 포함·제외

날짜 표현 바로 뒤에 붙는 표현은 아래 기준으로 판단. 앞 표현이 시간 단위(시·분·초)면 결합 표현까지 모두 미태깅.

| 구분 | 표현 | 처리 | 예시 |
|---|---|---|---|
| 범위·방향 | 부터, 까지, 까지만, 부터만, 이후, 이전, 이래 | 포함 | `<2019년부터: DT>` / `<이달 말까지: DT>` / `<3일까지만: DT>` / `<2019년 이후: DT>` |
| 경과 | 만 (경과 의미) | 포함 | `<5년 만: DT>`에 / `<3일 만: DT>`에 |
| 지속·근사·분배 | 간, 동안, 내내, 가량, 정도, 쯤, 께, 경, 씩, 이내, 안팎, 여, 약, 한, 총 | 포함 | `<100년간: DT>` / `<2일 동안: DT>` / `<9월쯤: DT>` / `<2002년경: DT>` / `<15일 이내: DT>` / `<내년 하반기께: DT>` |
| 한정 | 중, 안, 내 | 포함 | `<내년 2분기 중: DT>`에 / `<올해 안: DT>`에 / `<3일 안: DT>`에 |
| 상대 시점 | 전, 후, 뒤, 때, 초, 말, 중순, 하순 | 포함 | `<100년 전: DT>` / `<3일 후: DT>` / `<7월 초: DT>` / `<지난달 말: DT>` |
| 비교·수량 | 연속, 이상, 이하, 보다, 대비 | 제외 | `<3년: DT>` 연속 / `<10일: DT>` 이상 / `<전년: DT>`보다 / `<전월: DT>` 대비 |
| 일반 조사 | 은/는/이/가/을/를/도/에/의/에서 | 제외 | `<올해: DT>`도 / `<3일: DT>`에 |
| 한정 보조사 | 만 (한정 의미) | 제외 | `<올해: DT>`만 |

- 범위 짝 'A부터 B까지', 'A에서 B까지', 'A에서 B 사이', 물결표 범위는 전체 하나: `<3일부터 5일까지: DT>` / `<22일부터 이달 말까지: DT>` / `<3~5일: DT>` / `<4세기에서 6세기경: DT>`
- 'A부터'와 'B까지' 사이에 다른 문장 성분이 끼면 각각 분리
- 오답 → 정답: `<3일: DT>`까지만 → `<3일까지만: DT>` / `<5년: DT>` 만에 → `<5년 만: DT>`에 / `<올해 안에: DT>` → `<올해 안: DT>`에 / `<2019년부터 4년 연속: DT>` → `<2019년부터 4년: DT>` 연속

## 6. 미태깅 대상

| 유형 | 예시 |
|---|---|
| 시각 | 3시, 3시 30분, 15시, 정오, 자정 |
| 시간 단위 길이 | N시간, N분, N초, 반나절, 24시간, 3시간 동안, 30분간, 10분째, 2시간 전 |
| 하루 안 시간대 | 오전, 오후, 새벽, 아침, 점심, 저녁, 밤, 밤새, 밤사이, 하룻밤, 밤낮, 주야 |
| 시간만으로 된 범위 | 오전 9시부터 오후 6시까지 |
| 반복 주기 | 매일, 매주, 매달, 매월, 매년, 매해 |
| 순서·차례 | n일 차, N년차 (1일차, 8년차), 순서 의미의 n일째 (3일째 되는 날), 날 수 세기 (공휴일은 31일밖에 안 된다) |
| 기념 횟수 | N주년 |
| 기호형 경과 | D+6 |
| 복합어 | 하루하루 |
| 일반 개념으로 쓰인 시기어 | 방학이 좋다 (특정 시기일 때만 태깅) |
| 시기를 확정할 수 없는 시대어 | 현대 |
| 연호 단독 | 건문 |
| 회차·순번 | 제34회, 21대 |

주의: '시대', '시기', '시절', '당시'는 시간 단위가 아님. '1박', '2박 3일'의 '박'은 일 단위로 `DT`.

## 7. 다른 태그와의 경계 (DT 관련 경계의 정본)

| 구조 | 처리 | 예시 |
|---|---|---|
| 가운뎃점 월·일 숫자 + 사건명 | 전체 `EV`. 숫자만 `DT` 금지 | `<12·3 비상계엄: EV>` / `<4·19 혁명: EV>` / 오답 `<12·3: DT>` 비상계엄 |
| 단위어 갖춘 자립 날짜 + 사건명 | 날짜 `DT`, 사건 `EV` 분리 | `<지난해 12월3~4일: DT>` `<불법계엄: EV>` / `<2024년 12월 3일: DT>` `<비상계엄 선포: EV>` |
| 사건명 + '때' | 전체 `DT` | `<한일 월드컵 때: DT>` / `<2002올림픽 때: DT>` |
| 날짜 + 사건명 + '때' | 날짜와 '사건명 + 때'를 각각 `DT` | `<지난 2002년: DT>` `<한일 월드컵 때: DT>` |
| 사건명 + '당시' | 사건명만 `EV`, '당시'는 태그 밖 | `<불법계엄: EV>` 당시 / `<12·3 비상계엄: EV>` 당시 |
| 단독 '당시' | `DT` | 그는 `<당시: DT>` 상황을 기억하지 못했다 |
| '지난·오는' + 사건명 | '지난·오는' 제외, 사건명 `EV` | 손흥민은 지난 `<아시안게임: EV>`에서 |
| 행사명 앞뒤 연도 | 연도 `DT`, 행사명 `EV` 분리 | `<2025: DT>` `<서울모빌리티쇼: EV>` |
| 2자리 연도 축약 + 행사명 | 전체 `EV` | `<88 서울 올림픽 경기: EV>` |
| 날짜 + 회차 + 상 | 날짜만 `DT`, 회차·상 미태깅 | `<2000년: DT>` 제34회 `<납세자의 날: DT>` 대통령상 |
| 명절·법정 기념일·기념의 날 | `DT` | `<설날: DT>` / `<식목일: DT>` / `<지구의 날: DT>` 캠페인 |
| 기념 주년 행사·사업명 | `ev.txt` 기준 | 광복 80주년 기념 행사 |
| 왕 이름 + 시대·때 | 전체 `DT` | `<성종 때: DT>` / `<조선 성종 때: DT>` |
| 왕 이름이 인물 자체 | `PS` | `<정조: PS>` 대왕 |
| 국가·왕조명 + 때·시대 | 전체 `DT` | `<고려 때: DT>` / `<고려시대: DT>` |
| 리그 시즌 구분 | 시즌 표현은 리그명과 분리 | `<KBO리그: EV>` 정규시즌 |

## 8. 세부 판단

- 상대 시점·지시어도 시간 표현으로 쓰이면 태깅: 오늘, 어제, 내일, 모레, 그제, 이날, 그날, 당일, 전날, 다음날, 이튿날, 첫날, 둘째 날, 첫해, 그해, 한 해
- 분기·반기·시즌: `<1분기: DT>` / `<올해 3분기: DT>` / `<하반기: DT>` / `<올 시즌: DT>` / `<시즌 후반: DT>`
- 한자어 상대 시점은 하나로: 전년, 익년, 금년, 명년, 예년, 당해, 전월, 익월, 금월, 당월, 전주, 익주, 금주, 차주, 전일, 익일. '전'과 '년'으로 분해 금지
- 기간 길이는 용도와 무관하게 `DT`: 징역 `<1년: DT>` / 집행유예 `<2년: DT>` / `<6년: DT>` 계약
- 부정 수량 + 날짜 단위도 `DT`: `<수년 전: DT>` / `<몇 달 동안: DT>` / `<십수 년: DT>` / `<여러 해: DT>`
- n일: 기간·날짜 의미면 `DT` (커플 `<31일: DT>` 기념). n일째: '동안' 의미면 `DT` (`<3일째: DT>` 비가 내렸다)
- 숫자만 있어도 문맥상 날짜가 명확하면 `DT`: `<2021/7/10: DT>`
- 'n일 + 날', 'n월 + 달': 전체 하나 (`<10일 날: DT>`, `<9월 달: DT>`)
- 연호 + 연도: 전체 하나 (`<영락 1년: DT>`)
- 시대명 + 하위 시기·초기·중기·후기: 전체 하나 (`<고생대 오르도비스기: DT>`, `<중생대 초기: DT>`)
- 날짜 + 회차·순번: 분리. 주차·요일은 순번이 아닌 날짜 단위

## 9. 검수 체크리스트

| 확인 사항 | 오류 유형 |
|---|---|
| 기존 `DT`가 시각·시간대·시간 단위, 반복 주기, 순서·차례, N주년, 현대인가 | 오태깅 |
| 기존 `DT`가 가운뎃점 사건명의 숫자, '지난·오는' + 사건명, 행사명인가 | 태그 오류 |
| 시간 표현, 사건명 뒤 '당시', 비교·수량 표현, 일반 조사가 태그 안에 있는가 | 범위 확장 |
| 범위·경과·지속·한정·상대 시점 표현(부터, 까지, 만, 간, 중, 전)이 태그 밖에 있는가 | 범위 축소 |
| 하나의 시점(지난해 12월 3일), 범위 짝(3일부터 5일까지)이 쪼개졌는가 | 분리 |
| 날짜 + 요일, N주 + 요일, 날짜 + 시간, 대등 나열, 날짜 + 독립 사건명이 하나로 묶였는가 | 병합 |
| 문맥상 시간 기준·범위인 미태깅 날짜 표현(이날, 전년, 수십 년간)이 있는가 | 태깅 누락 |

판단 유보 조건: n일·n일째의 기간·순서 의미 확정 불가, 방학·시즌 등 시기어의 특정 시기 여부 불명, 국가·왕조명의 시대 의미 여부 불명, '만'의 경과·한정 의미 확정 불가.
