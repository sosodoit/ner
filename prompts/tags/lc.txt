# 태그별 검수 기준: LC (장소·지리)

## 1. 정의
현실 세계의 특정 국가, 행정구역, 도시, 자연 지형, 천체, 기타 장소를 식별하는 명칭.

## 5. 다른 태그와의 경계 (LC 관련 경계의 정본)

### 5.1. LC vs OG

| 단서 | 판정 | 예시 |
|---|---|---|
| 위치·소재·이동·출신·수식어 | `LC` | `<일본: LC>`을 찾은 관광객 / `<미국: LC>` 대통령 / `<고양시: LC>` 덕양구 |
| 협상·합의·요구·발표·부과·유치 등 행위의 주체, '~측', 경기 상대 | `OG` | `<미국: OG>`이 관세를 부과했다 / `<고양시: OG>`는 전국체전을 유치 / `<한국: OG>`과 `<일본: OG>`이 평가전을 치렀다 |
| 지명이 기관의 단순 소재지 | 분리 | `<미국: LC>` `<컬럼비아대학: OG>` |
| 지명이 기관명의 일부로 굳음 | 전체 `OG` | `<광주교육청: OG>` / `<서울중앙지방법원: OG>` |
| 지명이 구단 정식 명칭의 일부 | 전체 `OG` | `<의정부 KB손해보험: OG>` |
| 문맥으로 결정 불가 | `LC` 우선 | — |

국가명·지자체명의 서술어별 세부 기준은 `og.txt` 7.12 참조.

### 5.2. LC vs AF

| 단서 | 판정 | 예시 |
|---|---|---|
| 해변·지역·장소 의미 | `LC` | 해변 의미 `<경포대: LC>` / `<해운대: LC>` 가 볼 만한 곳 |
| 누각·건물·구조물 의미 | `AF` | 누각 의미 `<경포대: AF>` |
| 도로명 | `AF` | `<해운대로: AF>` |
| 사거리·로터리가 '~에 있다', 구간 등 위치를 뜻함 | `LC` | `<미아사거리: LC>`가 가장 막히는 구간이다 / `<미아사거리: LC>`에 있는 현대백화점 |
| 사거리·로터리가 길 자체를 뜻하거나 문맥 판단 불가 | `AF` | `<법원검찰청 사거리: AF>`도 이름을 바꿀 수밖에 없다 |
| 'OO보', 'OO전망대' | `AF` | `<세종보: AF>` |
| 문화재 미지정 유적·마을 | `LC` | `<토성민속마을: LC>` |
| 문화재 지정 유적·마을 | `AF` | `<아산외암민속마을: AF>` |
| 지역명 + 정식 건축물명 | 분리 | `<잠실: LC>` `<롯데월드타워: AF>` |
| 지역명 포함 전체가 정식 건축물명 | 전체 `AF` | `<잠원 한강공원 수영장: AF>` |

### 5.3. LC vs DT
국가명·왕조명이 시대를 가리키면 `DT`: `<조선 성종 때: DT>`. 장소를 가리키면 `LC`.

### 5.4. LC vs EV
지역명이 그곳에서 열린 행사를 가리키면 `EV`: `<평창: EV>` 티켓 / 부산국제영화제 … `<부산: EV>` 레드카펫.

### 5.5. LC vs OG (상점)
개별 상점·음식점은 '~에 가다', '~에서 만나다'와 결합해도 `OG`: `<다이소: OG>`에 갔다. 백화점·쇼핑몰 등 복합 상업 공간이 만남·구매 장소로 쓰이면 `LC`: `<롯데백화점: LC>`에서 만나기로 했다.

## 6. 세부 판단

- 국가명 의미와 언어·버전 의미가 불분명하면 `LC` 우선
- '해운대' 등 행정구역·해변·역을 모두 뜻할 수 있는 명칭은 장소 의미이면 모두 `LC`
- 과거 수도·소멸 도시도 `LC`
- '신도시', '지구', '테크노밸리'는 앞에 고유 지역명이 결합하여 특정 지역을 지칭할 때만 전체 `LC`
- 대학 등 기관 + 하위 공간(체육관, 강당)은 기관명만: `<경기대학교: OG>` 체육관

## 7. 검수 체크리스트

| 확인 사항 | 오류 유형 |
|---|---|
| 기존 `LC`가 4절 미태깅 대상인가 | 오태깅 |
| 기존 `LC`가 행위 주체·경기 상대(OG), 구조물·도로(AF), 시대(DT), 행사(EV)인가 | 태그 오류 |
| 기관 행위 주체로 쓰인 국가·지자체가 `LC`인가, 위치로 쓰인 국가가 `OG`인가 | 태그 오류 |
| '지방', '지역', '대륙' 등 설명 일반 명사가 태그 안에 있는가 | 범위오류 > 범위축소 |
| 명칭의 일부인 유형어(강, 산, 반도)가 빠졌는가 | 범위오류 > 범위확장 |
| 법정동 명칭·굳은 지역명이 쪼개졌는가 | 범위오류 > 태깅병합 |
| 연속 지역명·주소가 하나로 묶였는가, 지역명 + 비공식 시설명이 하나로 묶였는가 | 범위오류 > 태깅분리 |
| 문맥상 특정 장소인 미태깅 고유 명칭이 있는가 | 태깅 누락 |

판단 유보 조건: 국가·지자체가 장소인지 행위 주체인지 서술어로 확정 불가, 장소·건축물 겸용 명칭의 의미 확정 불가, 정식 건축물명 여부 확인 필요, 문화재 지정 여부 확인 필요.
