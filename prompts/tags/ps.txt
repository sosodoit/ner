# 태그별 검수 기준: PS (인물)

## 1. 정의
특정 사람, 역사·신화·종교 속 인물, 가상 캐릭터, 반려동물을 식별하는 이름·별칭·활동명. 음악 아티스트 그룹명 포함.

## 2. 하위 유형

| 하위 유형 | 태깅 대상 | 예시 |
|---|---|---|
| 인명 | 실존·비실존 인물의 이름, 예명, 필명, 세례명, 활동명, 별명, SNS·인터넷 사용자명, 음악 아티스트 그룹명 | 김종국, 아이유, 기안84, 곽튜브, @엊그제, 방탄소년단 |
| 캐릭터 | 작품 속 등장인물, 가상 캐릭터, 우화·전래동화 속 의인화 개체 | 해리포터(인물), 가렌, 어린왕자 속 장미 |
| 반려동물 | 반려동물의 고유한 이름 | 뽀삐, 쿠키, 바둑이 |

## 3. 태깅 범위

| 구조 | 처리 | 예시 |
|---|---|---|
| 이름 + 조사 | 조사 제외 | `<지영: PS>`이랑 `<승원이: PS>`가 |
| 이름 + 호칭·직책 | 이름만 | `<문재인: PS>` 대통령 / `<김: PS>` 박사 / `<윤: PS>` 대통령 |
| 성씨 + 호칭 '씨' | 성씨만 | `<김: PS>` 씨, 이것 좀 봐. |
| 명사구 전체가 굳어진 인명 | 전체 | 가수 `<김씨: PS>` / 신바람 `<이박사: PS>` / `<나폴리 맛피아: PS>` |
| 이름에 포함된 접사 | 포함 | `<영숙이: PS>` / `<승원이: PS>` |
| 독립된 인물 둘 이상 | 각각 | `<정조: PS>` 대왕 `<이산: PS>` |
| 두 사람을 묶은 커플명 | 개별 인명으로 복원 가능하면 요소별 | `<송: PS>` `<송: PS>` 커플 |
| 그룹명 + 멤버명 | 각각 | `<블랙핑크: PS>`의 `<제니: PS>` |

## 4. 미태깅 대상

- 특정 개인을 지칭하지 않는 포괄적 표현
- 가문·집단을 뜻하는 성씨: 민 씨는 조선 시대 명문가 중 하나 → 미태깅
- 익명 이니셜: A씨, B씨, A양, C군
- 직책·직업·관계: 대통령, 기자, 엄마 (6개 태그 밖)
- 실제 이름이 아닌 동물 유아어: 야옹이, 멍멍이, 꿀꿀이
- 음악 그룹의 소속사·레이블, 팬클럽·팬덤명, 그룹명과 같은 제목의 앨범·곡

## 5. 다른 태그와의 경계

| 혼동 | 판단 기준 | 예시 |
|---|---|---|
| PS vs OG (음악 그룹) | 노래·연주하는 구성원들의 활동명이면 `PS`. 발표·데뷔·활동 서술어와 결합해도 `PS` | `<방탄소년단: PS>`이 신곡을 발표했다 |
| PS vs OG (그 밖의 집단) | 소속사·레이블, 상설 예술 조직(교향악단·합창단·극단), 스포츠팀·e스포츠 팀, 범죄·해킹 조직은 `OG` | `<하이브: OG>` / `<서울시립교향악단: OG>` / `<T1: OG>` / `<김수키: OG>` |
| PS vs OG (인명이 기관명 일부) | 인명이 기관 호칭에 포함되면 전체 `OG`. 인명 + 정부·내각·정권은 분리 | `<김대중도서관: OG>` / `<조은석 내란 특검팀: OG>` / `<이명박: PS>` `<정부: OG>` |
| PS vs OG (감독명 + 호) | 감독 이름으로 부르는 팀은 `OG` | `<윤덕여호: OG>`(號) |
| PS vs AF (작품명) | 작품을 지칭하면 `AF`, 등장인물을 지칭하면 `PS` | `<김지영: AF>` 보러 갔는데, `<김지영: PS>`이 한 말이 와닿더라 |
| PS vs AF (인물명 재지칭) | 인물명이 그 인물의 작품을 가리키면 `AF` | 정말 `<모차르트: AF>` 너무 어렵다 (피아노 소나타 지칭) |
| PS vs AF (인간문화재) | 인간문화재로서의 지위·대상을 가리키는 문맥의 실명은 `AF` (프로젝트 결정). 그 밖의 인명은 `PS` | 인간문화재 `<공옥진: AF>` |
| PS vs DT (왕 이름 + 시대·때) | 재위 시기를 나타내면 전체 `DT` | `<성종 때: DT>` / `<정조 시대: DT>` |
| PS vs AF (뮤직비디오) | 가수명 + 곡명이면 가수명 `PS`, 곡명 `AF`. 영상 작품 제목 전체면 하나의 `AF` | `<BTS: PS>`의 `<'Dynamite': AF>` 뮤직비디오 |

## 6. 세부 판단

- 별명·비유 표현이라도 특정 개인을 지칭하면 태깅: 친구 `<철수: PS>`는 `<나무늘보: PS>`로 통한다 / 두 개의 심장 `<박지성: PS>`
- 유니트·서브유닛·프로젝트 그룹, 그룹 약칭도 `PS`: `<부석순: PS>` / `<소시: PS>`
- 음악 그룹을 다시 가리키는 '그룹', '팀'은 미태깅 (상위어 재지칭)
- 이름이 다른 개체명의 일부로 굳어진 경우 이름만 떼어 `PS` 태깅 금지: `<콩순이 말하는 냉장고: AF>`

## 7. 검수 체크리스트

| 확인 사항 | 오류 유형 |
|---|---|
| 기존 `PS`가 익명 이니셜·직책·가문 성씨·유아어인가 | 오태깅 |
| 기존 `PS`가 기관·팀·소속사·작품·인간문화재 문맥인가 | 태그 오류 |
| 음악 그룹명이 `OG`로 태깅되었는가 | 태그 오류 |
| 호칭·직책·조사가 태그 안에 있는가 | 범위오류 > 범위축소 |
| 굳어진 인명(김씨, 이박사)에서 일부만 태깅되었는가 | 범위오류 > 범위확장 |
| 인명 + 기관 호칭(김대중도서관)이 PS·OG로 쪼개졌는가 | 범위오류 > 태깅병합 |
| 두 인물(정조 대왕 이산)이 하나로 묶였는가 | 범위오류 > 태깅분리 |
| 문맥상 특정 인물·캐릭터·반려동물인 미태깅 이름이 있는가 | 태깅 누락 |

판단 유보 조건: 이름인지 일반 명사인지 불분명한 별명, 작품명·인물명 중 어느 쪽인지 문맥으로 확정 불가, 인간문화재 지칭 여부 불분명, 커플명의 개별 인명 복원 불확실.
