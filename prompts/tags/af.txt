# 태그별 검수 기준: AF (인공물)

## 1. 정의
사람이 제작하거나 창작한 구체적인 인공물의 명칭. 아래 하위 유형에 해당하는 대상만 태깅하며, 하위 유형 밖의 일반 인공물은 미태깅.

## 2. 하위 유형

## 5. 다른 태그와의 경계

| 혼동 | 판단 기준 | 예시 |
|---|---|---|
| AF vs OG (건물 겸 기관) | 물리적 구조물 서술어(보이다, 붕괴하다, 짓다, 신축되다, 공연이 열리다) → `AF` / 조직 활동 서술어(운영하다, 경영하다, 제작하다, 망하다, 정비에 들어가다) → `OG` / 판단 불가 → `OG` 우선 | `<LG아트센터: AF>`에서 공연이 열립니다 / `<LG아트센터: OG>`는 신작을 제작해 무대에 올린다 |
| AF vs LC (건물 겸 장소) | 만남·구매 장소로 쓰인 복합 상업 공간 → `LC`. 개별 상점은 `OG` | `<롯데백화점: LC>`에서 만나기로 했다 / `<다이소: OG>`에 갔다 |
| AF vs LC (길 겸 위치) | 사거리·로터리가 위치를 뜻하면 `LC` | `<미아사거리: LC>`가 가장 막히는 구간이다 |
| AF vs LC (유적·마을) | 문화재 지정 → `AF`, 미지정 → `LC` | `<아산외암민속마을: AF>` / `<토성민속마을: LC>` |
| AF vs OG (출판물 겸 언론사) | 읽기·구매 문맥 → `AF` | 오늘 아침 `<조선일보: AF>`는 읽을거리가 많았다 |
| AF vs OG (함선) | 함선 자체 → `AF`, 승조원 조직 → `OG`, 판단 불가 → `AF` | 한국의 구축함으로는 `<광개토대왕함: AF>` |
| AF vs PS (작품명·인물명) | 작품 지칭 → `AF`, 등장인물 → `PS` | `<해리포터: AF>` 시리즈는 … 소설은 `<해리포터: PS>`가 … |
| AF vs PS (인간문화재) | 인간문화재로서의 지위·대상을 가리키는 문맥의 실명 → `AF` (프로젝트 결정). 그 밖의 인명 → `PS` | 인간문화재 `<공옥진: AF>` |
| AF vs EV (공연 작품·공연 행사) | 앨범·곡·공연 작품 제목 → `AF`. 개최되는 콘서트·축제·쇼 → `EV` | 뮤지컬 `<명성황후: AF>` / `<방탄 콘서트: EV>` |
| AF vs 미태깅 (조약·법) | 법률·정책은 미태깅. 조약·협정은 `ev.txt` 기준 | — |

## 6. 세부 판단

- 운송 수단·악기·무기는 고유명이 없어도 구체적 종류명이면 태깅: `<자동차: AF>` 경적 소리 / `<기타: AF>`를 치며 / 한국형 `<소총: AF>` `<K-2: AF>`
- 악기 판단 서술어: 연주하다, 켜다, 타다, 치다, 불다. 전자악기는 소리를 만들다·찍다·표현하다도 인정
- 무기가 아닌 도구도 문맥상 공격 수단이면 `AF`: 농민들도 `<호미: AF>`와 `<낫: AF>`을 들고 왜군과 싸웠다
- 같은 작품이 원작·드라마·공연 등 다른 형태로 언급되어도 작품 제목이면 `AF`
- 웹툰·만화·애니메이션 제목은 `AF`: `<드래곤볼: AF>` / `<겨울왕국: AF>`
- 작품명 줄임말도 문맥상 확인되면 `AF`: 마블 영화보다 핫한 `<김지영: AF>`
- 따옴표 안의 작품명: 원문 표기를 바꾸지 않는 범위에서 작품명 전체 판단

## 7. 검수 체크리스트

| 확인 사항 | 오류 유형 |
|---|---|
| 기존 `AF`가 법률·제도·정책, 범주어·부품·가전, 장르, 코너명, 문자 체계 훈민정음인가 | 오태깅 |
| 기존 `AF`가 조직 활동 문맥(OG), 위치 문맥(LC), 등장인물(PS), 개최 행사(EV)인가 | 태그 오류 |
| 뮤직비디오 문맥의 가수명이 `AF`로 태깅되었는가 | 태그 오류 |
| 지정 등급·번호, 번지·호수, 코드형 모델명, 비공식 지명이 태그 안에 있는가 | 범위오류 > 범위축소 |
| 정식 명칭의 지명·상위 조직명, 국도 번호, 'n길', 모델·색상명, 시즌이 빠졌는가 | 범위오류 > 범위확장 |
| 정식 건축물명·문화재명·상품명이 지명·브랜드와 함께 잘못 쪼개졌는가 | 범위오류 > 태깅병합 |
| 지명 + 건축물, 브랜드 + 상품, 가수명 + 곡명이 하나로 묶였는가 | 범위오류 > 태깅분리 |
| 문맥상 특정 건축물·작품·상품, 운송 수단·악기·무기 종류명이 미태깅인가 | 태깅 누락 |

판단 유보 조건: 건물·기관·장소 의미를 서술어로 확정 불가, 정식 명칭 여부 확인 필요, 문화재 지정 여부 확인 필요, 인간문화재 지칭 여부 불분명, 상품명의 정확한 명칭 범위 불명.
