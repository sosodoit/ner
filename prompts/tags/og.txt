# 태그별 검수 기준: OG (기관·단체)

## 1. 정의
공동의 목적이나 기능을 위해 구성된 기관, 조직, 단체, 집단, 사업체의 명칭. 정부·행정기관, 기업·브랜드, 학교, 군, 언론사, 스포츠팀, 예술기관, 병원, 종교, 연구기관, 도서관, 법원·검찰, 정당, 음식점, 숙박업체, 기타 단체 포함.

## 3. 태깅 대상 판정

아래 중 하나에 해당하면 태깅 대상. 어디에도 해당하지 않으면 미태깅.

| 형태 | 기준 | 예시 |
|---|---|---|
| 고유 명칭 | 그 자체로 특정 조직을 식별 | `<공정거래위원회: OG>` |
| 관용 줄임말 | 4절 목록 또는 언론·공문에서 통용되는 축약형 | `<국수본: OG>` / `<국민: OG>`, `<신한: OG>` (5대 시중 은행) |
| 기관 통칭 | 정부·국회·검찰·경찰·법원·대법원·헌재·특검·공수처·지자체가 특정 기관으로서 행위하거나 행위를 받음 | `<검찰: OG>`이 기소했다 / `<경찰: OG>`에 신고하다 |
| 행정단위 줄임 표현 | 앞 문맥의 지자체를 '시·도·군·구'로 줄여 부르고 행정 주체로 서술 | `<양구군: OG>`은 (중략) `<군: OG>`에서 |
| 지점명 단독 | 앞 문맥에서 업체가 확인된 지점명 | (스타벅스 언급 후) `<한림점: OG>` |
| 원래 명칭의 일부 재지칭 | 고유 요소가 남은 재지칭 | 수원 삼성 … `<수원: OG>`이 이겼다 |

### 상위어 재지칭: 미태깅
앞 문맥의 기관을 기관 유형 일반 명사로 다시 부르는 경우는 그 기관을 가리키는 것이 분명해도 미태깅.

- 대상: 위원회, 본부, 사령부, 단, 청, 처, 원, 연구원, 연구소, 센터, 공단, 협회, 재단, 도서관, 학교, 대학, 대학교, 본교, 병원, 회사, 사(社), 본사, 그룹, 팀, 대표팀, 특검팀, 수사팀, 재판부
- 예: `<서울대학교: OG>`가 등록금을 동결했다. 대학교 측은 … → 대학교 미태깅
- 예: `<국가인권위원회: OG>`가 권고를 냈다. 위원회는 … → 위원회 미태깅
- 예: `<국립중앙도서관: OG>`이 개관했다. 도서관은 매주 월요일 휴관한다 → 도서관 미태깅
- 예: `<조은석 내란 특검팀: OG>`이 출범했다. 특검팀은 … → 특검팀 미태깅
- 앞 문맥 없이 단독으로 쓰인 위 표현도 미태깅. 단, '훈련소'는 고유 명칭이 없어도 `OG`

## 5. 태깅 범위

판단 테스트: 앞부분을 떼어도 뒤 기관명만으로 같은 기관이 특정되는가? 특정되지 않으면 통합, 특정되면 분리.

| 구조 | 처리 | 예시 |
|---|---|---|
| 인명·사건명 + 기관성 명사 | 전체 `OG`. 인명을 `PS`로 분리 금지 | `<조은석 내란 특검팀: OG>` / `<김건희 특검팀: OG>` / `<세월호 특별조사위원회: OG>` / `<국정농단 특검: OG>` / `<이화학당: OG>` |
| 인명·국가명 + 정부·내각·행정부·정권 | 분리 | `<이명박: PS>` `<정부: OG>` / `<한국: LC>` `<정부: OG>` |
| 인명 + 직책 | 직책 제외 | `<문재인: PS>` 대통령 / 전 `<국정원: OG>` 차장 |
| 지명이 단순 소재지 | 분리 | `<미국: LC>` `<컬럼비아대학: OG>` |
| 지명이 기관명의 일부 | 전체 | `<광주교육청: OG>` / `<스페인 대사관: OG>` / `<한국해양대학: OG>` |
| 지역명 + 구단 정식 명칭 | 전체 | `<의정부 KB손해보험: OG>` / `<서울 우리카드: OG>` |
| 국가 + 지명 + 법원 | 국가명 분리, 지명 + 법원 통합 | `<대한제국: LC>` `<법부: OG>` `<전라북도재판소: OG>` |
| 상위 기관 + 독립 하위 기관 | 전체 | `<경찰청 국가수사본부: OG>` |
| 상위 기관 + 내부 행정·교육 단위 | 상위 기관만 | `<공정거래위원회: OG>` 사무처 / `<부산대학교: OG>` 법학과 / `<홍익대: OG>` 미대 |
| 기관명 + 지점·캠퍼스·지사 | 전체 | `<신한은행 광화문점: OG>` / `<한양대학교 서울캠퍼스: OG>` / `<스타벅스 홍대점: OG>` |
| 설립 목적 수식어가 정식 명칭의 일부 | 전체 | `<내란극복·미래국방 설계를 위한 민관군 합동 특별자문위원회: OG>` |
| 일회적 수식어 (전, 해당, 이번, 산하, 소속, 제N차) | 제외 | 전 `<국정원: OG>` 차장 |
| 기관명 + 일상 회의·절차명 | 기관명만 | `<국가인권위원회: OG>` 전체회의 |
| 호텔명 + 객실명 | 호텔명만 | `<롯데호텔: OG>` 주니어 스위트룸 |

독립 하위 기관 판별: 자체 약칭이 있거나(국가수사본부 → 국수본), 문장에서 권한·업무의 주체로 서술되거나, 본부·사령부·청·처·원·단·위원회·연구원·센터 등 기관성 단위어로 끝나면 독립 기관. 소속 부서로만 언급되면 대표 기관만. 판별이 어려우면 판단 유보.

## 6. 미태깅 대상

- 3절 상위어 재지칭 및 앞 문맥 없는 기관 유형 일반 명사: 도서관에서 빌린 책 / 모든 백화점들이 할인 행사를 시작했다
- 사람·직위·인력을 뜻하는 기관 통칭: 경찰 50명, 경찰 간부, 국회의원, 조 특검(특별검사 개인), 지자체장
- 직업 의미: 경찰로 일하다
- 법·상·제도·정부 별칭의 일부: 검찰과거사위법, 참여정부
- 제도 일반론: 특검을 도입하는 게 원칙
- 장소 의미의 기관명 (`LC` 또는 `AF` 검토): 국회에서 열린 회의
- 회의·절차 명칭: 임시회, 정기회, 전체회의, 합의제행정기관
- 산업·기업 유형 일반명: 방위산업체
- 의학 분과·진료과목 일반명, 의료 체계: 정형외과, 이비인후과, 한의학
- 유교 (철학사상)
- 종교명이 복합어 내부에 결합: 구가톨릭교도
- '우승팀', '준우승팀', 종목·국가 정보 없는 '대표팀'
- 상호명 없는 업소·'OO점': 고양이 카페, (상호 미확인) 한림점
- 지명 + 일반 명사 '산장': 속초 산장
- 음악 아티스트 그룹명 (`PS`)

## 7. 하위 유형별 세부 판단과 경계

### 7.1. 경제
- 경제 협의체 자체는 `OG`, 그 회의·포럼은 `EV`: `<G20: OG>` 회원국 / `<G20 정상회의: EV>` / `<다보스포럼: EV>`
- 브랜드 + 상품명은 분리: 디올 `<립글로우 006 베리: AF>` (디올은 `OG`)
- 산업단지·기업 공장은 `LC`: `<구로공단: LC>` / `<현대오일뱅크 대산공장: LC>`

### 7.2. 교육
- 훈련소는 고유 명칭 없어도 `OG`: `<고용훈련소: OG>` / `<훈련소: OG>`
- 학과·단과대학은 미태깅, 상위 학교만 태깅

### 7.3. 군사
- 군 기관 줄임말은 단독으로도 `OG`: `<방첩사: OG>는 의혹을 부인했다`
- 군함: 승조원·조직을 대표하면 `OG`, 함선 자체면 `AF`, 판단 불가 시 `AF`
  - `<광개토대왕함: OG>`은 자매결연을 맺고 봉사활동 / 한국의 구축함으로는 `<광개토대왕함: AF>`

### 7.4. 미디어
- 기자·취재·보도·경영 등 조직 활동 문맥 `OG`, 읽기·구매 등 출판물 문맥 `AF`
  - `<조선일보: OG>` 출입기자 / 오늘 아침 `<조선일보: AF>`는 읽을거리가 많았다
- 채널명·프로그램명은 `AF`: `<SBS파워FM: AF>`

### 7.5. 스포츠
- 리그 명칭의 `EV`/`OG` 구분은 `ev.txt` 5.3 정본 따름
- 종목 명시 대표팀은 `OG`: `<양궁 대표팀: OG>` / 한국 `<축구 국가 대표팀: OG>`
- 경기 참가팀·상대로 쓰인 국가명은 `OG`: `<우즈베키스탄: OG>`이 `<카타르: OG>`에 비기면
- 운동시설이 운영 주체면 `OG`, 물리적 시설이면 `AF`
  - `<여의도 한강 공원 수영장: OG>`은 시설 정비에 들어갔다 / `<여의도 한강 공원 수영장: AF>`이 보인다

### 7.6. 예술
- 운영하다·경영하다·제작하다·망하다 → `OG` / 공연이 열리는 건물 → `AF`
  - `<LG아트센터: OG>`는 신작을 제작해 무대에 올린다 / `<LG아트센터: AF>`에서 공연이 열립니다
- 음악 아티스트 그룹은 `PS`. 소속사·레이블·상설 예술 조직·협회는 `OG`
  - 판별: 무대에서 노래·연주하는 구성원들의 이름이면 `PS`, 계약·경영·관리의 주체인 조직이면 `OG`

### 7.7. 의료
- 상호·고유명으로 특정되는 의료기관만 `OG`: `<쎈정형외과: OG>`

### 7.8. 종교
- 종교 자체 명칭도 `OG`: `<불교: OG>`, `<기독교: OG>`

### 7.9. 과학
- 상위 기관 + 부설 연구기관은 전체 `OG`
- 국가 연구기관 중 과학기관은 과학 유형 (태그는 동일하게 `OG`): `<국립수산과학원: OG>`

### 7.10. 도서관
- 인명 + 도서관이 정식 기관명이면 전체: `<김대중도서관: OG>`

### 7.11. 법률
- 특검 이름·사건명 + 특검·특검팀·특별수사본부는 전체 `OG`
  - 정답: `<조은석 내란 특검팀: OG>` / 오답: `<조은석: PS>` 내란 `<특검팀: OG>`
- 여러 법률기관이 연속하면 각각 태깅

### 7.12. 정부·정치 (국가명·지자체명 OG/LC 경계 정본)

| 단서 | 판정 | 예시 |
|---|---|---|
| 협상·회담·합의·갈등의 당사자, 요구·파병·관세 부과·지원·반박의 주체, '~측' | `OG` | `<미국: OG>`이 관세를 부과했다 / `<우크라이나: OG>` 측에 합의안을 전달했다 |
| 경기·평가전의 상대·참가팀 | `OG` | `<한국: OG>`과 `<일본: OG>`이 평가전을 치렀다 |
| 소재지·목적지·출신·수식어 | `LC` | `<일본: LC>` `<도쿄: LC>` / `<미국: LC>` 대통령 / `<중국: LC>` 기업 |
| 왕조·시대 | `DT` | `<조선 성종 때: DT>` |
| 광역·기초 지자체가 권한·정책·예산·시행의 주체 | `OG` | `<강원특별자치도: OG>`가 미래산업을 육성한다 / `<서울시: OG>`는 대책을 발표했다 |
| 지자체명이 위치·주소 | `LC` | 강원특별자치도 춘천에서 열렸다 → `<강원특별자치도: LC>` / `<서울시: LC>` `<강남구: LC>` `<역삼동: LC>` |
| '시·도·군·구' 단독이 앞 문맥 지자체의 행정 주체 | `OG` | `<서울시: OG>`는 … `<시: OG>`는 내년 예산에 반영할 방침이다 |
| '시·도·군·구' 단독이 장소 | `LC` 검토 | 시 외곽으로 이사했다 / 도 경계를 넘어 |
| 문맥으로 결정 불가 | `LC` 우선 | — |

- '여야 통합 정부', '여야 정부'는 전체 `OG`
- '지방자치단체', '지자체', '기초지자체'가 지방정부를 가리키면 `OG`
- 기관 통칭(검찰·경찰·법원·정부·국회 등): 수사·기소·판결·발표·제출 등 기관이 하는 일, 또는 신고·출석·체포·기록 요청 등 기관을 상대로 하는 일과 결합하면 `OG`
  - `<검찰: OG>`이 기소했다 / `<법원: OG>`에 수사기록을 보냈다 / `<경찰: OG>`에 따르면 / `<정부: OG>` 지원사업 / `<여당: OG>` 후보

### 7.13. 음식 업체
- 상호 + 지점명은 전체: `<스타벅스 홍대점: OG>`
- 개별 음식점·카페는 장소 서술어와 결합해도 `OG`

### 7.14. 숙박 업체
- 호텔·모텔·민박·펜션·콘도·리조트·상호 산장은 `OG`. 야영장·체험장 등은 `LC` 검토

### 7.15. 기타 기관·단체
- 국제기구, 시민단체, 재단, 클럽, 수비대 등: `<유네스코: OG>`에서 포럼을 개최하였다 / `<YMCA: OG>`에서 주관하는 행사 / `<국경수비대: OG>`에 잡혀
- 사람 이름처럼 보여도 조직이면 `OG`: 북한 해킹 조직 `<김수키: OG>`

### 7.16. OG vs AF·LC 일반 판정

| 서술어·문맥 | 판정 |
|---|---|
| 다니다, 경영하다, 운영하다, 차리다, 흥하다, 망하다, 발표하다, 제작하다 | `OG` |
| 보이다, 흔들리다, 붕괴하다, 짓다, 만들다 (물리적 구조물) | `AF` |
| 만나다, 가다 (복합 상업 공간·쇼핑몰) | `LC` |
| 문맥으로 결정 불가 (기관 겸 건물: 청와대, 국립중앙박물관) | `OG` 우선 |

- `<롯데백화점: OG>`을 경영하면서 / `<롯데백화점: LC>`에서 만나기로 했다 / 명동에 있는 `<롯데백화점: AF>`은 1979년에 지어졌다
- 인왕산에 오르면 동쪽으로 `<청와대: AF>`가 보인다 / `<청와대 본관: AF>`은 1991년에 신축되었다

## 8. 재등장 처리

- 같은 기관이 여러 문장에 다시 나오면 출현마다 태깅
- 앞 문장에서 확인된 기관 정보는 뒤 문장의 줄임말·지점명·행정단위 줄임 표현 판단에 계속 활용. 문장 단위로 문맥 초기화 금지

## 9. 검수 체크리스트

| 확인 사항 | 오류 유형 |
|---|---|
| 기존 `OG`가 상위어 재지칭, 인력·직위, 제도 일반론, 회의명, 진료과목 등 6절 대상인가 | 오태깅 |
| 기존 `OG`가 음악 그룹(PS), 위치(LC), 건물·출판물·함선(AF), 대회(EV)인가 | 태그 오류 |
| 행위 주체·경기 상대인 국가·지자체가 `LC`로 태깅되었는가 | 태그 오류 |
| 직책, 일회적 수식어(전·산하·소속·제N차), 회의명, 학과·객실명이 태그 안에 있는가 | 범위오류 > 범위축소 |
| 정식 명칭의 지명·수식어·지점명·상위 기관명이 빠졌는가 | 범위오류 > 범위확장 |
| 인명·사건명 + 기관 호칭이 `PS`·`EV` + `OG`로 쪼개졌는가 | 범위오류 > 태깅병합 |
| 소재지 지명 + 기관, 인명 + 정부가 하나로 묶였는가 | 범위오류 > 태깅분리 |
| 관용 줄임말, 기관 통칭, 행정단위 줄임 표현, 지점명이 기관을 가리키는데 미태깅인가 | 태깅 누락 |
