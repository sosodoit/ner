# 태그별 검수 기준: EV (사건·행사)

## 1. 정의
특정 시간·장소에서 발생하거나 개최·수행된 구체적인 사건, 사고, 행사, 활동의 명칭. 하나의 구체적 사건·행사로 특정되는 경우에만 태깅.

## 2. 하위 유형

| 하위 유형 | 태깅 대상 | 예시 |
|---|---|---|
| 사회운동·선언 | 구체적 사회운동·개혁운동, 역사적 선언 | 공민권운동, 새마을운동, 갑오경장, 3·1 운동, 인권선언, 노예해방선언 |
| 전쟁·혁명 | 전쟁, 전투, 군사작전, 반란, 혁명, 정변, 반정 | 러일전쟁, 황산벌 전투, 인천상륙작전, 4·19 혁명, 갑신정변, 12·12 군사반란 |
| 스포츠 행사 | 스포츠·e스포츠 경기, 대회, 리그 대회, 토너먼트 단계, 특정 경기 | 서울올림픽, 마라톤 대회, A매치, 챔피언스리그, 카라바오컵 4강전, 3파전, LoL 월드챔피언십 |
| 축제 | 축제, 영화제, 콘서트, 박람회, 엑스포, 모터쇼, 행사 콘텐츠 | 보령머드축제, 칸 영화제, 방탄 콘서트, 서울모빌리티쇼, 록 페스티벌 |
| 기타 사건·사고·행사 | 사건, 사고, 참사, 사태, 캠페인, 회의, 정상회담, 학술대회, 전시회, 시사회, 팬사인회, 시험, 경진대회, 선거, 체험행사 | 세월호 참사, 위화도 회군, 천안문사태, 일본 불매운동, G20 정상회의, 다보스포럼, 한·미 정상회담, 총선, 12·3 비상계엄 |

사건·행사 판단 서술어: 개최하다, 열리다, 치르다, 실시하다, 시행하다, 발생하다, 일어나다, 참가하다, 우승하다, 선포하다. 해당 문장만으로 불분명해도 기사 전체 문맥에서 사건·행사로 확인되면 태깅.

## 3. 태깅 범위

판단 테스트: 앞부분을 떼어도 뒷부분만으로 같은 사건이 특정되는가? 특정되지 않으면 통합, 특정되면 분리.

| 구조 | 처리 | 예시 |
|---|---|---|
| 가운뎃점 월·일 숫자 + 사건명 | 전체 | `<12·3 비상계엄: EV>` / `<5·18 민주화운동: EV>` / `<6·25 전쟁: EV>` |
| 2자리 연도 축약 + 행사명 | 전체 | `<88 서울 올림픽 경기: EV>` / `<88 서울: EV>` |
| 개최지 + 행사명 | 전체 | `<서울 올림픽 경기: EV>` / `<부산국제영화제: EV>` |
| 행사명 중간에 낀 연도 | 전체 | `<도드람 2024-2025 V리그: EV>` / `<CFS 2025 그랜드 파이널: EV>` |
| 행사명 앞뒤에 붙은 연도 (따옴표 안이어도 동일) | 연도 `DT` 분리 | ‘`<2025: DT>` `<서울모빌리티쇼: EV>`’ / `<Passenger Terminal Expo: EV>` `<2025: DT>` / `<2018: DT>` `<평창동계올림픽: EV>` |
| 단위어 갖춘 자립 날짜 + 사건명 | 날짜 `DT` 분리 | `<지난해 12월3~4일: DT>` `<불법계엄: EV>` |
| 회차 + 행사명 (제N회, N대) | 회차 미태깅, 행사명만 | 제24회 `<서울올림픽경기: EV>` / `<1957년: DT>` 제1회 `<퍼그워시 회의: EV>` |
| 고유 식별 요소 + 참사·사태·사건·의혹 | 전체 | `<세월호 참사: EV>` / `<국정농단 사태: EV>` / `<선감학원 사건: EV>` |
| 대회명 + 토너먼트·컵 단계 | 전체 | `<카라바오컵 4강전: EV>` / `<호주오픈 16강: EV>` / `<FA컵 4라운드: EV>` / `<KPGA 오픈 3라운드: EV>` |
| 이닝 'N회' + 초·말 | 'N회'만 | `<9회: EV>` 말 |
| 사건명 + '당시' | 사건명만 | `<불법계엄: EV>` 당시 |
| 행사 제목 안의 인명·날짜를 하나로 묶을 수 없는 경우 | 유형 명칭만 `EV`, 인명·날짜는 각 태그 | 의상스님 탄신 1400주년 기념 `<학술대회: EV>` |

## 4. 미태깅 대상

| 유형 | 예시 |
|---|---|
| 제도·조치 일반으로서의 계엄·비상계엄·긴급조치 | 계엄이 선포되면 헌법상 권리가 제한될 수 있다 |
| 시기를 특정할 수 없는 개념·사조·장기 사회 변화 | 프롤레타리아혁명, 4차 산업혁명, 르네상스, 농업혁명 |
| 일반 행위·전술·운동 형태 | 사보타주, 시위 방식 |
| 상·훈장·메달·트로피·시상 부문, 행사명을 포함한 수상명 | 대종상, 경제정의기업상, 대통령상 |
| 일상 회의·방송 | 국무회의, TV토론, 임시회, 정기회 |
| 사업·제도·용역·교육과정 (~사업, ~용역, ~정비사업, ~지원, ~과정) | AI 바우처 지원사업, 연신내역 도심 공공주택복합사업, 철도망 구축 효율화 방안 용역 |
| 선거·시험 일반론 | 역대 대선 투표율, 선거 때 |
| 선거 관련 복합어 | 대선 경선 후보 |
| 상위어 재지칭 | 이번 학술대회, 행사, 대회 (정식 행사명 언급 이후) |
| 정규리그 단순 순번, 단순 경기 수·횟수 | 23라운드, 총 32라운드, 14경기 |
| 문서·명령 자체를 뜻하는 칙령·조약·협정 | 밀라노 칙령(문서), 포츠머스 조약에는 ~내용이 쓰여 있다 |
| 화폐로서의 유로 | 유로화 환율 |
| 사건명 뒤 '때'로 만든 시점 (`DT`) | 한일 월드컵 때 |

## 5. 다른 태그와의 경계

### 5.1. EV vs DT
날짜·사건 결합의 정본은 `dt.txt` 7절. 요약:
- 가운뎃점 날짜 + 사건명 → 전체 `EV`
- 사건명 + '때' → 전체 `DT` / 사건명 + '당시' → 사건명만 `EV`
- '지난·오는' + 사건명 → '지난·오는' 제외, 사건명만 `EV`
- 명절·법정 기념일·기념의 날(설날, 어버이날, 지구의 날) → `DT`
- 기념 주년이 행사·캠페인·사업의 이름으로 쓰이면 → `EV`: `<광복 80주년: EV>` 기념 포스터

### 5.2. EV vs AF
- 개최되는 공연·콘서트·쇼 → `EV`. 앨범·곡·공연 작품의 제목 → `AF`
- 따옴표로 소개된 행사 콘텐츠(체험 프로그램, 증강현실 게임, 공연 쇼)가 구체적 행사로 소개되면 `EV`: ‘`<드론라이트쇼: EV>`’
- 조약·협정: 체결 행위·역사적 사건 → `EV`, 문서·내용 → 미태깅, 판단 불가 → `EV` 우선
  - 포츠머스 조약을 체결했다 → `<포츠머스 조약: EV>`

### 5.3. EV vs OG (리그·대회 명칭 정본)

| 단서 | 판정 | 예시 |
|---|---|---|
| 개최·우승·시즌·경기·시상 등 열리는 대회 | `EV` | `<KBO리그: EV>` 정규시즌 / `<V리그 챔피언결정전: EV>` / `<챔피언스리그 16강: EV>` |
| 소속·출신·구단·출범 등 조직·무대 | `OG` | `<EPL: OG>` 출범 이후 / `<MLB: OG>` 구단 / `<MLS: OG>` 팀 |
| 리그를 운영하는 기관 | `OG` | `<한국야구위원회: OG>` |
| 경제 협의체 vs 그 회의 | 협의체 `OG`, 회의 `EV` | `<G20: OG>` / `<G20 정상회의: EV>` |

'정규시즌', '포스트시즌' 등 시기 표현은 리그명에 포함하지 않음.

### 5.4. EV vs LC
지역명이 그곳의 행사를 가리키면 `EV`: `<평창: EV>` 티켓 / 부산 레드카펫 → `<부산: EV>` (부산국제영화제 지칭).

## 6. 세부 판단

### 6.1. 보통명사 행사명
문맥상 하나의 구체적 행사를 지칭하면 행사 유형 명칭도 `EV`: 축제, 마라톤 대회, 학술대회, 간담회, 결승전, A매치. 단, 정식 행사명이 이미 나온 뒤의 상위어 재지칭은 미태깅.

### 6.2. 사건·사고
행사가 아닌 사건·사고·사회 현상은 발생 시기·장소·맥락이 구체적으로 확인될 때만 태깅. 사건·회담 이름은 `EV`: `<한·미 정상회담: EV>` / `<북·미 대화: EV>` 채널 / `<롯데리아 회동: EV>`. 정상회담·협상은 일시·장소·참가 주체가 특정될 때만.

### 6.3. 계엄·국가 권력 행사
- 날짜 수식어 + 계엄·조치 → 전체 `EV`: `<12·3 비상계엄: EV>` / `<10·17 비상조치: EV>`
- 성격·평가 수식어(불법, 위헌, 내란, 친위) + 계엄 → 수식어 포함 `EV`: `<불법계엄: EV>` / `<위헌적 비상계엄: EV>` / `<내란: EV>`
- 수식어 없는 '계엄'도 앞 문맥의 특정 사건을 가리키면 `EV`
- 제도·조치 일반이면 미태깅. 표현이 있다는 이유만으로 태깅 금지

### 6.4. 선거·시험
- 특정 시기·회차의 선거를 가리키면 약칭도 `EV`: 대선, 총선, 지방선거, 지선
  - 이재명 `<대선: EV>` 후보 / 내년 `<지방선거: EV>` / 지난해 `<총선: EV>`
- 선거명 앞 회차(제N대, N대, 제N회)는 태그 밖
  - 제21대 `<총선: EV>`이 있었습니다 / 19대 `<대선: EV>` / 제8회 `<전국동시지방선거: EV>`
  - 오답: `<19대 대선: EV>` / `<제21대 총선: EV>`
- 주민투표·수능·임용고시 등도 특정 시행 회차가 문맥상 명확할 때만

### 6.5. 스포츠
- 'N라운드', 'N회', 'N세트', 'N경기', 'N강': 특정 경기·단계 자체면 `EV`, 단순 수량·횟수면 미태깅
- 단계만 단독으로 특정 경기를 가리켜도 `EV`: 이번 `<4강전: EV>`
- 'n파전'이 특정 경기·경쟁 구도면 `EV`: `<3파전: EV>`
- '유로'가 대회면 `EV`, 화폐면 미태깅

## 7. 검수 체크리스트

| 확인 사항 | 오류 유형 |
|---|---|
| 기존 `EV`가 제도 일반 계엄, 개념·사조, 수상명, 일상 회의, 사업·용역, 선거 일반론, 상위어 재지칭, 단순 순번, 문서 의미 조약인가 | 오태깅 |
| 기존 `EV`가 리그 조직(OG), 작품(AF), 기념일·'때' 시점(DT)인가 | 태그 오류 |
| 열리는 대회인 리그명이 `OG`로, 행사 지칭 지역명이 `LC`로 태깅되었는가 | 태그 오류 |
| 회차, 앞뒤 연도, 자립 날짜, '당시', '지난·오는', 초·말, 시즌 표현이 태그 안에 있는가 | 범위 확장 |
| 가운뎃점 날짜, 개최지, 행사명 중간 연도, 성격 수식어, 토너먼트 단계가 빠졌는가 | 범위 축소 |
| 가운뎃점 날짜 + 사건명, 대회명 + 단계가 쪼개졌는가 | 분리 |
| 연도 + 행사명, 자립 날짜 + 사건명, 회차 + 선거명이 하나로 묶였는가 | 병합 |
| 문맥상 구체적 사건·행사인데 미태깅인가 | 태깅 누락 |

판단 유보 조건: 계엄·선거 등의 특정 사건 지칭 여부 불명, 조약의 사건·문서 의미 확정 불가, 리그명의 대회·조직 의미 확정 불가, 행사 콘텐츠의 행사·작품 여부 불명, 연도의 행사명 일부 여부 불명.
