# NER LLM 검수 룰

## 목적
뉴스 기사 문장의 기존 개체명 태깅 오류 탐지. 룰 결과 TRUE는 오류, FALSE는 정상 의미. 태깅누락은 검수 범위에서 제외.

---

## 용어 정의
- **표현**: 문장 내 문자열 후보
- **개체명**: 태깅 대상으로 판정된 표현
- **태그**: 개체명에 부착하는 6개 대분류(PS·LC·OG·AF·DT·EV)
- **하위 태그**: 대분류별 세부 유형. 「하위 태그 판단표」 기준. 출력하지 않고 내부 판단에만 사용
- **경합 태그**: 같은 표현이 문맥에 따라 대신 부착될 수 있는 다른 태그 또는 하위 태그. 혼동 가능성이 높아 LLM_E002에서 반드시 비교하는 대상
- **제외 대상**: 하위 태그와 형태·의미가 유사하나 태깅하지 않는 표현. 단독 태깅 시 LLM_E001, 태그 범위 내 포함 시 LLM_E003 판정 기준

---

## 공통 전제
- **결과값**: TRUE → `review_status: error`, FALSE → `review_status: normal`
- **판단 유보**: 오류 가능성은 있으나 확정 근거가 불충분하면 TRUE + `review_needed: true`
- **판정 순서**: 개체명 단위 E001 → E002 → E003 순차 적용. E001이 TRUE이면 이후 룰 생략. S001은 문장 단위 독립 적용
- **복합 오류**: E002와 E003이 모두 TRUE이면 `error_lv1: tagging_error`, `error_lv2`에 해당 범위 유형 기록
- **문맥 판단**: 문장과 동일 기사 앞뒤 문장 문맥으로 지칭 대상 판정. 개체명 문자열만으로 판단 금지
- **원문 보존**: 원문의 띄어쓰기·문장부호·표기 변경 금지, 문장 전체 재작성 금지
- **하위 태그**: 출력하지 않고 판정 근거로만 사용. 「하위 태그 판단표」 기준

## LLM_E001

- **룰(질문)**: 기존 태그 `<X: T>`의 X가 이 문맥에서 특정 대상을 다른 대상과 구별하여 지칭하지 않거나, 태깅 제외 대상에 해당하는가?
- **처리방식**
  - **질문 구성**: ① 문장과 앞뒤 문장으로 X의 지칭 대상 확인 → ② 특정 대상 지칭 여부 판정 → ③ 제외 기준 대조 → ④ 인정 예외 확인
  - **판단 기준 (해당 시 TRUE)**
    - 일반명사, 유형어, 수량, 기능 설명. 단, 유형 보통명사 허용 대상은 FALSE(「하위 태그 판단표」의 '보통명사 허용' 표시 태그)
    - 6개 태그 밖 범주: 직위·직업·호칭, 회차·수량, 시각·시간대, 법률·제도·정책·사업, 상·훈장, IT 서비스·SW·HW·모델 일련번호, 언어, 국민·민족(한국인), 음식·의류
    - 상위어·보통명사 재지칭(대학교 측, 위원회, 시, 본부, 이번 대회)
    - 복합어 내부 요소(경찰차의 경찰, 한국적의 한국)
    - 익명 이니셜(A씨), 가문 성씨, 반복 주기(매일·매년), 가상 장소, OO바위, 4대강, 제도 일반을 뜻하는 '계엄', 선거 일반론(역대 대선)
    - 「하위 태그 판단표」 제외 대상 열 해당 표현
  - **인정 예외 (FALSE)**: 줄임말·약칭(국수본, 한은), 부분 지칭(수원→수원 삼성, 부산→부산국제영화제), 비유적 쓰임
  - **판단 유보**: 단독 기관 유형 명사(검찰, 경찰, 법원, 정부, 국회)의 기관 체계 지칭과 앞 기관 대명사적 쓰임 구분 불가 사례
  - **수정안**: `corrected_span`은 태그를 제거한 원문
- **탐지오류유형**: 오태깅
- **태그**: 전체

## LLM_E002

- **룰(질문)**: X의 실제 지칭 대상이 부착된 태그 T와 다른 대분류에 속하는가?
- **처리방식**
  - **질문 구성**: ① 서술어, 공기 명사, 앞뒤 문장으로 지칭 대상 확정 → ② 대분류 판정 → ③ 「하위 태그 판단표」로 해당 대분류의 하위 태그 후보 판정(특정 불가 시 대분류 재판정, 경합 태그 열 확인) → ④ 경합 쌍 비교 → ⑤ 문맥 판단 불가 시 기본 우선순위 적용
  - **경합 쌍 판단 기준**

    | 경합 쌍 | 판단 기준 |
    |---|---|
    | PS↔AF | 작품명은 AF, 등장인물은 PS, 인간문화재 문맥의 실명은 AF |
    | PS↔OG | 음악 그룹은 PS, 소속사·상설 예술단체·스포츠팀·범죄 조직은 OG |
    | LC↔OG | 국가·지자체가 행위 주체, 협상 당사자, 경기 상대, '~측'이면 OG. 소재지·배경·수식어면 LC. 왕조·시대 의미면 DT |
    | LC↔AF | 도로·보·전망대·문화재 마을은 AF. 위치를 나타내는 사거리, 비지정 유적·마을은 LC |
    | OG↔AF↔LC | 공연장·백화점·박물관: 운영·제작 → OG, 짓다·보이다 → AF, 만나다 → LC. 개별 상점은 OG. 신문: 보도 → OG, 읽다 → AF. 군함: 조직 → OG, 함선 → AF |
    | OG↔EV | 리그: 소속·출범 → OG, 개최·시즌·우승 → EV |
    | DT↔EV | 가운뎃점 날짜가 붙은 사건명 → EV. 사건명+'때' → DT. 공휴일·기념일(지구의 날) → DT. 기념 행사명 → EV |
    | AF↔EV | 조약: 체결 사건 → EV. 공연 작품 → AF, 행사 → EV |

  - **기본 우선순위**: 청와대·국립중앙박물관 → OG, 미아사거리 → AF, 국가·시 → LC, 제주도·시베리아·역명과 같은 지명 → LC, 인명 계열 → PS. 적용 시 `reason`에 '우선순위 적용' 명시
  - **판정 원칙**: 같은 대분류 내 하위 태그 차이는 FALSE이며, 판정 근거로만 활용
  - **수정안**: `<X: 수정 태그>`
- **탐지오류유형**: 태그오류
- **태그**: 전체

## LLM_E003

- **룰(질문)**: X의 태그 범위에 불필요한 문자열이 포함되었거나, 명칭을 구성하는 문자열이 빠졌거나, 서로 다른 개체명이 하나의 태그로 묶였는가?
- **처리방식**
  - **질문 구성**: ① 정식·관용 명칭의 전체 범위 확인 → ② 앞부분 제거 시 같은 대상 특정 여부 판단(특정되면 분리, 특정되지 않으면 통합) → ③ 최장 단위 원칙과 최소 단위 예외 대조 → ④ 확장·축소·분리 판정
  - **범위축소 (TRUE): 태그 안에 다음이 포함되어 범위를 줄여야 하는 경우**
    - 조사, 직위·호칭, 미스·미스터
    - 회차(제N회, 제21대), 전·해당·이번·산하·소속, 당시, 대비, 연속·이상·이하·보다
    - 시각·시간대, 지정 등급(국보 제N호)
    - 괄호 기호와 괄호 안 관계어(이하, 약칭)
    - 행사명 앞뒤의 독립 연도
    - 학과·사무처·객실명
  - **범위확장 (TRUE): 태그 밖으로 다음이 빠져 범위를 넓혀야 하는 경우**
    - 명칭으로 굳어진 지명·인명·사건명(광주교육청, 조은석 내란 특검팀, 김대중도서관)
    - 가운뎃점 날짜(12·3 비상계엄), 인명 접미사 '-이'(영숙이)
    - 날짜에 붙는 부터·까지·이후·만·간·쯤·초·말, '지난/오는'+날짜
    - 지점·캠퍼스명, 상품의 모델·버전명, 도로의 'n길', 대회 단계(4강), 행사명 중간의 연도
  - **태깅분리 (TRUE): 하나의 태그 안에 다음이 묶여 각각 분리해야 하는 경우**
    - 연속 지역명, 지역명+건축물, 소재지+기관, 인명+정부
    - 날짜+요일, 날짜+시각, 대등 나열
    - 비공식 명칭(서울 올림픽공원 체조경기장), 브랜드+상품명, 커플명, 괄호 안의 다른 표기
    - 중첩 태그(`<A(<B: X>): Y>`)
  - **판단 유보**: 조사 융합(러시안데요)은 원문 변경 없이 판단 유보 처리
  - **수정안**: 오류 구간 전체를 수정 결과로 작성
- **탐지오류유형**: 범위오류 (범위축소, 범위확장, 태깅분리)
- **태그**: 전체 (DT·OG·EV·LC 중심)

## LLM_S001

- **룰(질문)**: 문장 안에서 서로 인접한 둘 이상의 태그가 하나의 개체명을 나누어 태깅하여 병합이 필요한가?
- **처리방식**
  - **질문 구성**: ① 문장 내 인접 태그 쌍 추출 → ② 두 태그를 합친 전체가 하나의 대상을 지칭하는지 판단 → ③ 최소 단위 예외 해당 여부 확인
  - **태깅병합 (TRUE): 인접 태그를 하나로 합쳐야 하는 경우**
    - 연+월+일, 지난해+날짜, 날짜 범위(3일부터 5일까지)
    - 상위 기관+독립 하위 기관(경찰청 국가수사본부)
    - 명칭으로 굳어진 인명·사건명+기관(조은석 내란 특검팀)
    - 호+이름(퇴계 이황), 정식 명칭인 건축물·시설(잠원 한강공원 수영장)
    - 상호+지점명(스타벅스 홍대점), 가운뎃점 날짜+사건명
  - **판단 기준 (FALSE)**
    - 최소 단위 예외: 연속 지역명, 지역명+건축물, 소재지+기관, 날짜+요일, 날짜+시각, 대등 나열, 인명+정부
  - **E003과의 구분**: 빠진 문자열에 태그가 이미 있으면 S001, 태그가 없으면 E003 범위확장
  - **기록 방식**: 분리된 태그 각각의 `entity_id`에 같은 `target_span`(분리 구간 전체)과 `corrected_span`(통합 태그) 기록
- **탐지오류유형**: 범위오류 (태깅병합)
- **태그**: 전체 (DT·OG·PS·AF 중심)

---

## 하위 태그 판단표

- **용도**: LLM_E002의 하위 태그 후보 판정, LLM_E001의 보통명사 허용 여부 판정
- **사용법**: 대분류 판정 후 정의에 부합하는 하위 태그 1개 선택. 어떤 하위 태그에도 부합하지 않으면 대분류 재판정 또는 LLM_E001 재검토
- **경합 태그 열**: LLM_E002 경합 쌍 비교 대상. 괄호는 해당 태그로 바뀌는 문맥 조건. '-'는 주요 경합 태그 없음
- **제외 대상 열**: 해당 표현이 단독으로 태깅되어 있으면 LLM_E001 TRUE, 다른 개체명의 태그 범위 안에 포함되어 있으면 LLM_E003 범위축소 TRUE. '-'는 별도 제외 대상 없음
- **보통명사 허용**: 고유명이 아닌 유형 명칭도 태깅 대상인 하위 태그. 그 외 하위 태그는 고유명 또는 문맥상 특정 대상 지칭 명칭만 대상
